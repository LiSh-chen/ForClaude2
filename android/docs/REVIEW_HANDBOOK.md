# 鄉鎮特色內容審查手冊

本手冊整理自專案負責人在審查過程中提出的全部意見。**所有鄉鎮特色（`android/app/src/main/res/raw/town_blurbs.txt`）的新增、修改、刪除，在給負責人看之前，都必須先經審查者（`town-content-reviewer` subagent）逐條審查並通過。** 審查者只負責挑問題與查證，不負責改寫；撰寫者依審查結果修正後，再送審，直到全部通過。

---

## 一、每條都要通過的七個問題（Q1–Q7）

| # | 問題 | 來源意見（舉例） | 不通過時 |
|---|---|---|---|
| Q1 | **外行人看得懂嗎？** 句中出現的人、地、詞、機制都要交代 | 油飯：「請補充工人在這做什麼」；壺穴：「讓人知道是什麼樣的地形」；巴拉告：「簡單敘述這種陷阱怎麼捕魚」；紅毛城：「補充原本建造的用途」 | 補背景 |
| Q2 | **同類很多，這一個特別在哪？** | 霞海城隍廟：「全台月老廟不只這間」；池上米：「跟其他米的差異」；平地溫泉：「少見的差異點在哪」；崁仔頂：「其他魚市都沒有嗎」；石獅石球：「很多廟都有」 | 補差異點；沒有就換角度或刪 |
| Q3 | **事件有頭有尾嗎？** | 總統府：「燒了三天，然後呢？為什麼現在還看得到」；中元祭：「現在到底在做什麼」；防空洞：「穿過後可接…但這些景點可以做什麼」 | 補後續、補「去了可以做什麼」 |
| Q4 | **記憶點測驗：讀完能一句話轉述給朋友嗎？** | 北門：「這對大家會特別想記嗎」；鐵道公園：「完全不會想記」；十三行：「這些遺跡有什麼值得記憶」 | 換更有份量的角度；名稱、年份、落款類不寫 |
| Q5 | **日常行為（散步、騎車、拍照、看外觀）有沒有說出此地為什麼特別？** | 「不是不要寫，而是寫了要強調在這個地方做這些日常行為特別的點」 | 說明特別之處，或刪 |
| Q6 | **來源措辭是否中性、恰當？** | 「『區公所形容』完全不適合」；「創始店容易有爭議」；「之前不是說不會講特定的店嗎」 | 見第三節 |
| Q7 | **有沒有突兀、沒頭沒尾的句子？** | 龜山島：「最後冒出登島名額限制，莫名其妙」；壯圍沙丘：「清水模…沒頭沒尾」；蘇澳冷泉：「1928年被發現不是重點」；行政飛地：「完全不吸引人」 | 刪掉或接進前後文 |

**三大要素總檢查：吸引人、有特色、有記憶點。** 三者缺一，該條視為不合格；查資料補強後仍不合格就**刪除**（不硬湊，不是每區都要滿三條）。

## 二、禁止與必須（逐項核對）

### 不得出現
1. **有時效性的說法**：近年、如今、現在、目前、今年、正在增加／減少、數量變化、名額、開放時間、票價、營業狀況。（例：「近年數量減少」「海女人數正在減少」）
2. **特定店家名稱**，以及容易爭議的「創始店／發源店／最正宗」。
3. **沒有來源的玩笑或評語**（例：「威尼斯本人沒有表示意見」「點之前請先評估自己的嗅覺」）。
4. **點名機關當作形容的來源**（例：「區公所形容」「縣政府稱」）。來源不足時改用「相傳／據說／被稱為／一般認為」，或乾脆不寫。
5. **沒有說明成因的籠統形容**（例：「上升氣流穩定」卻不說原因 → 查得到原因就寫，查不到就改寫成有來源的事實）。
6. **單純行政或地理冷知識**（例：「行政飛地」）。
7. **只有名稱、年份、面積、設立經過而沒有畫面的條目**。

### 必須做到
1. **稱號先寫**：「第一／唯一／最／全台」等獨特稱號放在句子最前面，但**至少兩個獨立來源**查證，句尾加 `※`（App 不顯示 ※；沒有 ※ 的句子不得出現這些字）。單一來源的稱號只寫事實，不寫稱號。
2. **年份來源有出入時用不寫死年份的寫法**（例：「經修復完工」而不寫 1947至1948；「1940年代初」）。
3. **補機制**：石滬怎麼捕魚、巴拉告怎麼運作、壺穴怎麼形成，要用白話講清楚。
4. **補後續與用途**：被燒毀的建築為什麼還在、原本建來做什麼。
5. **「可以做什麼」要有吸引人的理由**：只寫活動不夠，要說明這項活動在此地特別在哪。
6. **以看的人的立場再讀一遍**：不認識這個地方的人看完，有沒有得到一個想記住的東西。

## 三、來源與查證規則

1. **分級**：A＝兩個以上獨立來源；B＝一個官方／權威來源；C＝單一二手來源或傳說。**C 級不收錄**。
2. 查證以搜尋結果可見內容為準；**不憑記憶寫**。看不到原文的不採用。
3. **外部審查意見（含其他 AI 的意見）不直接採用**，必須逐項用獨立來源核實：屬實才改，查不到或互相矛盾就保留原樣並註明，或把有爭議的數字／名稱拿掉。
4. 來源互相矛盾時（例如母乃／武乃石滬、瑞穗溫泉歸屬）：不選邊，改寫成只寫能確定的部分。
5. 傳說、口述、單一報導一律加「相傳」「據說」，且不以此下稱號。

---

## 四、行政區歸屬規則

1. 條目掛在哪一區，以**景點本體的行政區**為準（以 Google 地圖與官方地址交叉核對）。
2. 景點跨區或活動範圍跨區時，掛在核心標的所在區，並在句中交代（例：外傘頂洲「行政上屬雲林口湖鄉，卻漂到東石外海」）。
3. 發現放錯區（例：劉銘傳隧道在仁愛區、嘉義城隍廟在東區）要**搬到正確的區**，並向負責人說明是自己資料整理的錯誤。
4. 搬走後該區若變成 0 條，不得讓該區沒有內容。

## 五、格式規則（App 內容檢查會自動擋）

- 一行一區：`縣市|區名|🙂 標籤:句子|🙂 標籤:句子|…`；每區 1–3 條。
- 句子 14–90 字；句中不得有 `:` 或 `|`。
- 句子結尾可加 `※`（僅限已查證的稱號）。
- 禁字：`最｜唯一｜第一｜全台｜全國｜僅存`（沒有 ※ 時）。
- 新增文字若含字型沒有的字，要重新裁切字型檔。

---

## 六、呈現規則（給負責人看的內容）

1. **依縣市分組**，每一條都要**完整呈現修正後的內容**（不只列修改的部分）。
2. 每一條後面要有**檢視結果**：通過／修正（說明改了什麼、為什麼）／偏平淡（說明缺什麼）／刪除（說明原因）。
3. 修正前後要有對照（原／新）。
4. 新內容要先給負責人確認，確認後才併入；負責人說「先不要刪」的，就先不要刪。
5. 查不到而保留原句的，要誠實說明是「查不到」，不要說成「沒問題」。
6. 版面相關：判斷畫面比例時給整張畫面截圖；資訊不要用滑動解決。

## 七、審查流程

```
撰寫者（主 Claude）改寫／新增／刪除
        ↓  送審（附：改動清單、各條來源）
審查者（town-content-reviewer）逐條對照本手冊 → 回報 PASS / FAIL（含規則編號、理由、查證結果）
        ↓  有 FAIL
撰寫者修正 → 再送審（直到全部 PASS）
        ↓  全部 PASS
才給負責人看（附審查者的審查記錄）
```

審查者的回報格式：

```
條目：<縣市|區|標籤>
判定：PASS / FAIL
違反：<Q1..Q7 / 禁止第N項 / 必須第N項 / 來源規則 / 行政區規則 / 格式>
理由：<一兩句>
查證：<若查了來源：結果與連結>
建議方向：<只給方向，不代寫>
```

審查者的原則：
- 只讀、只查證、只回報，不修改 `town_blurbs.txt`。
- 看不確定、查不到的，標為「無法查證」，不當作通過。
- 對撰寫者的來源也要抽查，不信任「已查證」的字樣。

## 八、第一輪審查後補充（審查者指出的手冊遺漏，2026-11）

1. **稱號同義詞也算稱號**：首條、首座、首次、全球、全世界、少數、初代、之冠、無雙等，與「第一／唯一／最」同樣需要兩個獨立來源並標 `※`；機械檢查擋不到，由審查者人工比對。
2. **「獨立來源」的定義**：兩篇文章轉載同一個評選、同一份新聞稿、同一份官方資料，只算一個來源。至少要有兩個「各自查證或各自發布」的來源（例如官方公告加獨立媒體）。
3. **時效用語擴大範圍**：除了近年、如今、現在、目前，也包含「至今」「仍」「仍會」「可搭乘」「假日點燈」「目前開放」這類營運與現況說法。例外：祭典、民俗的固定週期（例如「每年農曆七月」）可以寫，因為那是活動本身的規則，不是現況。
4. **會變動的數字**：普查數量、族群數、造價、產量等逐年變動的數字，不寫單一數字，改寫成區間或「數百到上千」，或乾脆不寫。
5. **標籤 emoji**：每條的 emoji 依內容選擇，手冊中的 `🙂` 只是示意。
6. **地名由來類**：仍適用 Q4；沒有畫面、沒有故事的地名由來一律不收。
7. **文化資產類別**：寫「國定古蹟／縣定古蹟／歷史建築／文化景觀」時，以文化部公告名稱與類別為準。
8. **PASS 要註明依據**：審查者的每個 PASS 要標明是「已查證」還是「僅閱讀」，不得把「僅閱讀」當作屬實。
9. **內容可能被截斷**：句子沒有收尾（缺句號）時，先確認是否被截斷，再判定 Q3、Q7。
10. **罕用字**：句中有罕用字（例如「硓𥑮石」）時，要確認字型檔有裁入。
