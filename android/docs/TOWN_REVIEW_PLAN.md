# 鄉鎮特色檢討計畫（依你的意見整理）

## 一、檢討標準：每一條都要回答這七個問題
| # | 問題 | 來自你的哪一則意見 | 不通過時怎麼做 |
|---|---|---|---|
| 1 | 外行人看得懂嗎？句子裡出現的人、地、詞，有沒有交代清楚 | 油飯：「請補充工人在這做什麼」 | 補上背景（誰、在哪、做什麼） |
| 2 | 同類的東西很多，這一個特別在哪？ | 霞海城隍廟：「全台月老廟不只這間」 | 補上與同類相比的獨特點；找不到就降級或換角度 |
| 3 | 事件有沒有頭有尾？ | 總統府：「燒了三天，然後呢？為什麼現在還看得到」 | 補上後續與結果，讓人明白今天為什麼還能看見 |
| 4 | 讀完想轉述給朋友嗎？（記憶點測驗） | 北門：「這件事對大家會特別想記嗎」 | 改用更有份量的角度；只是名稱、年份、落款的不寫 |
| 5 | 日常行為（散步、騎車、看建築）有沒有說出在這裡為什麼特別 | 前一輪意見 | 說出特別的原因，或刪掉 |
| 6 | 來源不足時的措辭 | 「區公所形容」不適合 | 不點名機關；單一或較弱的來源改用「相傳／一說／被形容為」，或不寫；稱號要兩個以上來源 |
| 7 | 有沒有突兀的句子（名額、規定、時間）？ | 龜山島：「登島名額限制」 | 刪掉，或接到前後文裡解釋 |

## 二、作法（逐縣市進行）
1. 每條用上面七個問題打分，寫出沒通過的是哪一題。
2. 沒通過的先查資料補；查不到就誠實標「偏平淡」，不編。
3. 重寫，並用「完全不認識這個地方的人」的眼光再讀一次。
4. 每個縣市完成後，給你「檢視結果＋完整內容」。
5. 全部完成後再給你完整列表。

### 修正後完整內容（臺北市）
- 🍵 包種茶鄉：南港舊莊一帶是北台灣包種茶的發源地，相傳茶以方形毛邊紙包裝而得名；早年茶農還拌入桂花薰製，南港因此種了許多桂花，桂花也是南港區花。
- 🌋 陽明山：陽明山小油坑的噴氣孔終年冒出蒸氣，步道上能看到針狀、晶狀的硫磺結晶，空氣滿是硫磺味，還聽得到噴氣口爆裂聲；大屯火山已被確認為活火山。
- 🍚 油飯魚丸湯：大稻埕是淡水河邊的貿易重鎮，台北橋一帶聚集大量靠勞力做工的人，糯米耐餓，油飯成了早餐；店家在油飯上鋪半熟荷包蛋，再配魚丸湯。
- 💘 霞海城隍廟：霞海城隍廟1859年創建，廟只有46坪，卻因旁祀的月下老人聞名；廟方曾改請月老出巡吸引目光，外國遊客尤其日本遊客特地來求姻緣。
- 🏛️ 總統府：總統府前身是1919年完工的臺灣總督府，1945年5月空襲後大火燒了三天；1947至1948年間修復完工，外觀與原建築差異不大，改名介壽館，如今仍是總統府。
- 🚪 北門：北門又稱承恩門，是台北府城現存四座城門中唯一沒有改建、保有清代原貌的一座，其餘三座在1960年代中期改建；旁邊的高架橋已拆除，改成廣場。❖
