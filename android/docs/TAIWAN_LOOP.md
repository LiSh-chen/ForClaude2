# 台灣環島（第一條路線）

順時針：台北 → 東岸南下 → 蘇澳搭火車到花蓮 → 花東縱谷 → 南迴舊路過壽卡 → 恆春半島 → 西岸北上 → 淡水搭渡輪到八里 → 台北。
火車與渡輪兩段不計步數。距離為各景點直線距離 ×1.2 的**估算值**。
所有座標與事實的來源見 `TAIWAN_LOOP_RESEARCH.md`（原始查證）；本表的座標都是有來源的數字，十個字特色都對應查證過的事實。
特例：林田山的座標由來源提供的 TWD97 值（X 290624, Y 2623821）換算；布袋、恆春古城為鄉鎮中心附近的約略位置。
