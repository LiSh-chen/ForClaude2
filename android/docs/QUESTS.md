# 任務與里程碑

完成任務時會跳出慶祝視窗（`RouteEvent.QuestCompleted` → `QuestCompletedDialog`）。獎勵尚未決定：`Quest.reward` 為 null 時顯示「獎勵即將開放」。

## 機制
- `core/.../Quest.kt`：`Quest`（指定景點卡集合 `cards`、指定鄉鎮集合 `towns`、或空集合＝「任意 N 個」）與 `QuestEngine`（算進度、找出剛完成的）。
- `shared/.../CollectionStore.kt`：終身帳本（景點卡、走過的鄉鎮「縣市|名」、已慶祝的任務），跨路線、跨圈數；納入備份。
- `AppViewModel.recordQuests`：每次 `settleRoute`（每 0.5 公里，抵達終點必算）把目前路線的收集寫入帳本，並對新完成的任務送出事件。第一次執行只靜默標記已完成者，避免舊玩家一次被跳出一堆視窗。
- `ui/QuestCatalog.kt`：任務清單由資料產生（縣市景點／縣市鄉鎮、四大區域、里程碑、主題組合）。新增主題組合只要在 `COMBOS` 加一列（景點卡 id）。
- 「收藏」頁最上方按鈕可查看全部任務與進度。

## 任務種類
| 類別 | 內容 |
|---|---|
| 里程碑 | 5/10/20/30 張景點卡、全收集；10/30/60 個鄉鎮區 |
| 縣市・景點 | 集滿某縣市的所有景點卡 |
| 縣市・足跡 | 走遍某縣市所有有特色的鄉鎮區 |
| 區域 | 北／中／南／東台灣的全景點、全鄉鎮 |
| 主題 | 北台灣經典、跨越北回歸線、鹽與糖的故事、國境之南、花東縱谷、廟宇巡禮、港口小鎮、老街漫步 |
