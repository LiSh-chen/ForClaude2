# 任務：查證景點「實際長相」，供圖像提示詞使用

目的：我們用 AI 畫插圖，之前只憑文字資料寫提示詞，畫出來和實景不像。請你**查證每個景點的實際外觀**，我再據此改寫提示詞。

## 每個景點請回報（繁體中文，條列，精簡）
1. **最能認出它的 3–5 個外觀特徵**：建築形式、屋頂/塔/門的形狀、層數、主要顏色與材質、標誌性物件、擺放與格局、周圍環境（海、山、田、街）。要具體到能讓畫家照著畫（例如「紅磚底座、白色塔身、四角錐屋頂」），不要籠統形容詞。
2. **最常見的取景角度**（從哪裡看過去最有代表性）。
3. **容易畫錯的地方**（常見的誤解或其他類似景點的特徵混進來，例如把 A 廟畫成 B 廟的樣子；動作姿態如神像是坐是站；有沒有某個部件）。
4. **需要避免出現的**：文字、招牌內容、會過時的物件。
5. **來源**：每個景點至少列 2 個**彼此獨立**的網頁（官方觀光網、維基、文化部/文資局、可靠旅遊誌、新聞）。外觀細節若只找到一個來源，要註明「單一來源」。**不要憑記憶寫；找不到就說找不到**。

## 規則
- 這是**查證實物外觀**，不是歷史介紹。不寫年代、規格、沿革，除非它直接影響外觀（例如「1975 年整修加上紅色尖頂」會影響畫法）。
- 整個任務最多 38 次 WebSearch（standard）；WebFetch 連不上，只能靠搜尋結果摘要。一次搜尋盡量涵蓋多個特徵（例如「景點名 外觀 特色 建築 照片」「景點名 格局 平面 入口」）。
- 不要修改 repo 其他檔案、不要 git commit。

## 輸出
寫成 `visual_out_N.md`（N 是你的編號），每個景點一節，標題用景點 id 與名稱；最後回報哪些景點外觀證據偏弱。
