# 基隆市、新北市 逐條重審（七個問題）

## 基隆市

### 七堵區
- 🍲 臭粿仔湯：七堵臭粿仔湯是當地人的私房小吃，湯頭用大量豬頭骨熬煮，臭的是濃濃的骨頭味，和臭豆腐的臭不一樣；菜市場一帶就吃得到。
  - 檢視：修正（Q1、Q6）：原句的玩笑沒有來源，且沒說明臭的是什麼；改為骨頭味、與臭豆腐不同、哪裡吃得到
- ⛏️ 瑪陵坑：瑪陵坑在七堵西北山區，日治時期因煤礦吸引大量礦工而發展，礦業衰退後居民回頭務農；富民親水公園的賞桐步道，4月底到5月初桐花像白雪覆蓋山頭。
  - 檢視：修正（Q4）：原句只列煤礦、窯址、步道；改寫成礦工來了又走、回頭務農，加上桐花像白雪的畫面（焦炭窯查不到可靠來源，先拿掉）
- 🚂 鐵道紀念公園：七堵鐵道紀念公園保存日治時期的木造舊站房，因都市計畫而拆解編號，在三十公尺外重新組裝。
  - 檢視：通過：拆解編號再重組，說明了舊站房為什麼還在

### 暖暖區
- 🌀 壺穴：壺穴是水流夾帶砂石在河床凹處打轉、鑽蝕出的圓形深洞，基隆河從平溪到暖暖一帶沿岸處處可見。
  - 檢視：通過：圓形深洞怎麼磨出來已說明
- 🎵 車站主題曲：暖暖車站的主題曲就是梁靜茹的〈暖暖〉，她曾來這裡拍MV，這座沒有站務員的無人招呼站至今仍會播放。
  - 檢視：通過：說明了主題曲是〈暖暖〉

### 中正區
- 🏝️ 和平島：和平島的阿拉寶灣海蝕岩像一格格豆腐，入選「全球最美21個日出觀測點」；園區的海水泳池由舊九孔養殖場改建，夏天能在海蝕岩岸邊游泳。 ❖
  - 檢視：通過：豆腐岩日出稱號加海水泳池由舊養殖場改建
- 🌈 彩色屋：正濱漁港對岸的房屋外牆被塗成彩虹色，遊客稱它為台版威尼斯，威尼斯本人沒有表示意見。
  - 檢視：通過：有梗，但偏輕
- ⛵ 三府王爺巡江：農曆六月十五三府王爺聖誕，和平島社靈廟的王船在乩童相隨下沿正濱漁港一帶巡江；王爺海上遊江已登錄為基隆民俗無形文化資產。
  - 檢視：通過：王船、乩童與路線都具體

### 信義區
- 🔦 信二防空洞：信二防空洞是日本二戰時期挖的地下坑道，約300公尺，分東西兩坑，洞裡還留著燈泡、電線和通風口，岩壁滲出的泉水滴落有聲。
  - 檢視：通過：燈泡、電線、泉水滴落是進去才看得到的細節
- 🦇 劉銘傳隧道：劉銘傳隧道又稱獅球嶺隧道，是台灣第一條鐵路隧道，南北兩端同時開挖、因高度誤差得修改才接通；南口有劉銘傳題的「曠宇天開」匾額，洞裡住著台灣葉鼻蝠。 ❖
  - 檢視：修正（Q1、Q3）：原句沒說這是什麼隧道、為什麼重要；補上「台灣第一條鐵路隧道」與南口匾額（稱號有兩個來源，標 ※）。另請你確認：這條隧道在基隆的行政區，我的資料列在信義區，但有來源寫在安樂區

### 仁愛區
- 🐟 崁仔頂魚市：崁仔頂魚市每天約凌晨一點開始聚人，拍賣員站在攤子旁喊價，價高者得，這套拍賣方式從日治時期延續到現在。
  - 檢視：通過：凌晨一點喊價、延續日治拍賣方式
- 🏮 基隆中元祭：基隆中元祭由十一姓輪流主普，相傳起於清咸豐年間的漳泉械鬥，後來改以賽陣頭來化解紛爭。
  - 檢視：通過：十一姓輪流主普、賽陣頭化解械鬥

## 新北市

### 汐止區
- 🌊 水返腳：汐止舊稱水返腳，清代文獻記載潮水漲到此處折返，日治時期1920年改名汐止。
  - 檢視：通過
- 🚢 茶葉集散：水返腳街曾是茶葉集散地，烏龍與包種茶由河船運往大稻埕；老街上濟德宮因《通靈少女》取景而爆紅，廟裡軟身媽祖的四肢關節可轉動、能換新裝。
  - 檢視：通過

### 瑞芳區
- 🏭 水湳洞：水湳洞的十三層遺址依山而建，遠看像飄在空中的荒廢宮殿，有「台版天空之城」之稱，晚上還會亮起琥珀色燈光。
  - 檢視：通過
- 🐱 猴硐：猴硐車站一下車就是貓村，貓咪在老礦村的巷弄間閒晃（近年數量減少）；礦工當年運煤的橋還在，園區裡可搭礦車進去，試操作鑿岩機等工具。
  - 檢視：通過
- 💧 黃金瀑布：黃金瀑布的水是礦坑流出的礦水，鐵質氧化把岩壁染成金黃偏橘；下方的陰陽海，海灣黃褐色的水與外海藍色海水形成鮮明對比。
  - 檢視：通過

### 貢寮區
- 🏘️ 卯澳漁村：卯澳漁村保留百年石頭厝，石牆有平行砌、人字砌、亂石砌三種；卯澳灣水清見底，被潛水界人士讚為台灣浮潛天堂。
  - 檢視：通過
- 🍮 石花凍：貢寮澳底的海女在礁岩間採石花菜，經七洗七曬熬成晶瑩的石花凍，是夏天的清涼甜點；海女人數正在減少。
  - 檢視：通過
- 🥾 草嶺古道：草嶺古道經過雄鎮蠻煙碑，翻上埡口後視野豁然開朗，大里聚落、太平洋和龜山島盡收眼底，秋天滿山芒花，全程約8.5公里。
  - 檢視：通過

### 林口區
- 🏜️ 水牛坑：水牛坑是林口西濱旁裸露的砂泥岩壁，外型像峽谷，被稱為林口大峽谷，規模請不要抱太高期待。
  - 檢視：通過：自嘲式的提醒反而好記
- 🍵 龍壽茶：林口龍壽茶又稱半球型包種，墨綠半球狀、茶湯金黃回甘；林口台地常起霧，適合茶樹生長，產量高峰時佔新北市茶產量一半以上。
  - 檢視：修正（Q1）：發現原句把「包種」寫成「烏龍」，已更正；並補上林口台地起霧、產量高峰時占新北市茶產量一半以上

### 八里區
- 🍊 八里文旦：八里文旦面向淡水河口、種在排水良好的山坡地，果實皮薄汁多；近年栽植面積快速增加，有「南麻豆、北八里」的說法。
  - 檢視：修正（Q2、Q6）：原句只說產地與產季；改為面向河口的山坡地、皮薄汁多、近年快速擴大，有「南麻豆、北八里」的說法（不寫全臺排名）
- ⚓ 八里坌：清代八里坌曾設巡檢司，後來港口淤積、被淡水取代，如今只剩舊城里、舊城路等地名。
  - 檢視：偏平淡（Q4）：只剩舊城地名，暫無更好材料
- 🏺 十三行博物館：十三行博物館因1990年搶救十三行遺址而設，2003年開館，遺址距今約一千八百到五百年，建築刻意傾斜十七度。
  - 檢視：通過：建築刻意傾斜十七度

### 淡水區
- 🍢 阿給：阿給是把油豆腐挖空填入冬粉，再用魚漿封口蒸熟，淋上甜辣醬吃。
  - 檢視：通過
- 🥚 鐵蛋：淡水鐵蛋要反覆滷製再風乾，水分漸失、體積縮小，變得又韌又入味。
  - 檢視：偏平淡（Q2）：只講製作過程，沒說明為什麼是淡水的代表
- 🏰 紅毛城：紅毛城前身是西班牙人1620年代建的聖多明哥城，荷蘭人重建，1867年起租給英國當領事館。
  - 檢視：通過：西班牙、荷蘭、英國三段歷史
