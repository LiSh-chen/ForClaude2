# 任務（第二輪）：把一個景點的外觀查到「畫家能照著畫」的細節

背景：我們要把查到的外觀寫進 AI 繪圖提示詞，**不附參考照片**，所以描述必須夠具體、夠正確。上一輪只查到概略特徵，這輪要更細，而且要能互相印證。

## 要查的（對指定景點）
1. **整體構圖與格局**：從最常見的角度看，主體在哪、周邊有什麼（空地、山、道路、樹、其他建物），主體佔畫面比例。
2. **每個主要物件的形狀細節**：幾層、幾面、什麼屋頂（歇山、硬山、攢尖）、屋脊裝飾、柱子、門、基座、台階；材質與**顏色**（磚紅、白、灰、金、黑…）；大約高度比例（和人、和旁邊物件比）。
3. **標誌性小物件**：神像的樣子與姿勢（坐/站）、穿著顏色、臉色；金爐、石獅、碑、環、球、燈、旗等的數量與位置。
4. **哪些是「會變」或「會過時」的**（活動布置、施工、特展、廣告）——要避開。
5. **容易混淆的相似景點**，列出它們的差異（例如不是 X 的樣子）。
6. **來源**：每個細節盡量有 2 個獨立來源（官方觀光網、文化部/文資局、維基/維基共享資源檔案說明、可靠旅遊誌、新聞報導，**描述照片內容的圖說特別有用**）。只有 1 個來源就標「單一來源」；找不到就寫「未找到」，不要憑印象補。

## 規則
- 這是查證外觀，不寫歷史。
- 最多 38 次 WebSearch（standard）；WebFetch 連不上，只能用搜尋結果摘要。搜尋時多用「外觀」「造型」「長什麼樣」「照片」「圖說」「建築特色」「格局」「平面圖」「尺寸」「高度」「顏色」等詞，也試英文與日文關鍵字。
- 不要修改 repo 其他檔案、不要 git commit。

## 輸出
`visual2_out_N.md`：每個景點一節，依上面 1–6 條整理；最後附一段**「可直接用的英文繪圖描述草稿」**（150 字內，只含你有把握的細節，沒把握的不要寫），並標示信心高/中/低。
