# 任務：補查景點外觀的「具體細節」（第二輪，供寫圖像提示詞）

背景：上一輪（`visual_out_1/2/3.md`）已查到各景點大致外觀，但很多細節標「未找到」。使用者要我們**不給 AI 繪圖工具參考照片**，只用文字把景點外觀寫得夠具體，所以現在需要更精確的**視覺細節**。你和我都**看不到照片**（無法下載圖片），只能靠網頁文字：遊記、官方導覽、新聞、文化資產說明、維基類文字描述裡「長什麼樣」的句子。

## 要找什麼（每個景點都找，找不到就寫「未找到」，不要編）
- **顏色**：牆面、屋頂（瓦色）、柱子、門、塔身、底座的顏色。
- **材質**：磚、石、木、混凝土、鋼、琉璃瓦、剪黏、洗石子…
- **形狀與結構**：層數、屋頂形式（歇山、硬山、攢尖…）、門面開間數、拱數、塔的高度（公尺）與斷面（圓/方/三角/八角）、頂部造型。
- **標誌性物件的數量與位置**：例如石獅幾對、風車幾座、鳥居幾座、燈籠幾盞、階梯幾級，它們在畫面的哪裡。
- **周圍環境**：背景是海、山、田、馬路、市街；植物種類（榕樹、木麻黃、椰子…）；地面材質。
- **人與活動**：常見的人群與活動（不要寫個別人臉）。
- **畫錯風險**：容易與其他類似景點混淆之處（請明確寫出「不要畫成 X」）。

- hinoki 檜意森活村：牆面顏色（木色/白/漆）、屋瓦顏色、門窗、走廊、庭院與街道、是否有樹與圍牆。
- lukang 鹿港老街：街屋立面（磚色、有無騎樓、二樓窗）、街道寬度與鋪面、招牌風格（只寫風格，不寫字）、九曲巷與摸乳巷的牆面顏色與高度。

- hsinchu 新竹城隍廟：屋頂色與形式、廟門外觀、門前石獅/廣場、大算盤的位置（確認：在廟內中央或廟對面？）、周圍市街樣貌。
- taoyuan 桃園神社：本殿屋頂型式、材質與顏色（銅板瓦的顏色）、鳥居顏色與材質、參道長度與石燈籠數量、手水舍外觀、周邊樹木。

- tongxiao 通霄精鹽廠：園區入口、建築顏色與樣式、鹽造景（白色？形狀）、前方景觀、是否近海、有無水塔/煙囪。
- gaomei 高美濕地：風車塔身顏色與形狀、燈塔（紅白橫紋八角）的尺寸、木棧道寬度與弧度、濕地植物顏色、水面反光、夕陽時的顏色。
- shihsanhang 十三行博物館：八角塔的顏色與傾斜形狀、屋頂鋼構顏色、主建築的窗與入口、前方廣場。
- budai 布袋（好美寮／布袋港）：沙洲、潟湖、木麻黃防風林、蚵架、漁港船隻的樣子與顏色、水面顏色、天空氛圍。

## 規則
- 每項細節至少兩個**彼此獨立**的網頁印證才算「已確認」；只有一個來源標「單一來源」；互相矛盾要寫出兩種說法。
- 只寫外觀，不寫歷史。
- 整個任務最多 38 次 WebSearch（standard）；WebFetch 連不上。一次搜尋盡量涵蓋多個細節（例如「景點名 外觀 顏色 屋頂 遊記」）。
- 不要修改 repo 其他檔案、不要 git commit。

## 輸出
`visual2_out_N.md`：每個景點一節，用條列寫「已確認」「單一來源」「矛盾」「未找到」四類，並附一小段「可直接放進提示詞的描述句」（英文也可），句子只含已確認或單一來源的細節。最後回報哪些景點仍然缺很多。
