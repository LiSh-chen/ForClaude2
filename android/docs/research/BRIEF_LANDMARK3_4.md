# 景點卡補特點 — 查證簡報

## 任務
「來台灣走走」每張景點卡要有**三個特點**，每個特點 = 短標題（2–8 字）＋ 一句說明。下面每張卡列出「已有的特點」和「還缺幾個」。請為每張卡**補足缺的數量**，只回傳新增的特點。

## 規則（違反就不能用）
1. **查證**：每一句都要有**兩個互相獨立的來源**，或**一個官方來源**（政府、管理單位、博物館、官方網站、國家公園、文化部資料庫等）。維基百科＋另一個獨立來源可以；兩個網站互抄不算兩個。附上你實際看過的網址。查不到就回報「查無可靠來源」，**不要硬湊**。
2. **說明句**：繁體中文，14–70 個字（含標點），一句講完，不用「最、唯一、第一、全台、全國、僅存」等絕對說法（要用就改成「相傳／約／之一」並有來源）。
3. **有記憶點**：讀完會想講給朋友聽的小事（為什麼這樣叫、怎麼來的、有什麼特別做法、看得到什麼）。**避免**乾巴巴的年表、建築面積、官方宣傳語、營業資訊。
4. **不講店家**：不要出現任何商店、餐廳、品牌店名。可以講食物、技藝、地景、活動、建築、人物。
5. **不重複**：不得與該卡「已有的特點」、同一張卡其他新特點講同一件事；也盡量不與其他卡重複。
6. **標題**：2–8 字，名詞片語，不要加冒號。
7. 只寫現在仍然成立的事；有爭議的說法請寫成「相傳」並說明至少兩種說法或來源。
8. 不要碰：政治評論、宗教優劣、價格、地址、電話。

## 回傳格式（寫成檔案，每張卡一段）
```
### <id> <名稱>
- 標題｜說明句（14–70字）｜來源1網址｜來源2網址（官方來源可只列一個）
- …（缺幾個就寫幾個；查不到的寫「查無可靠來源」）
```
最後再列一行「已查但捨棄」的候選與原因（一兩行就好）。

## 本組負責的卡（第 4 組）

### lotuspond 蓮池潭
- 已有特點：（無）
- 還缺：3 個

### qiaotou 橋頭糖廠
- 已有特點：糖廠冰棒:橋頭糖廠自製冰棒有十餘種口味，米糕粥冰棒用桂圓與糯米甜粥做成。；綠色隧道:五分車鐵道沿線每隔一百公尺換一種樹，坐車像穿過一條綠色隧道。
- 還缺：1 個

### anping 安平古堡
- 已有特點：蚵灰窯:安平蚵灰窯文化館展示居民燒蚵殼製水泥，再混入糖與糯米水強化。；紅頂瞭望塔:安平古堡的紅頂瞭望塔不是荷治遺物，1944年所建，1975年整修才加紅色尖頂。
- 還缺：1 個

### jingzijiao 井仔腳鹽田
- 已有特點：瓦盤鹽田:井仔腳瓦盤鹽田相傳源於陳永華嫌平埔族煎鹽苦澀，改在埕上鋪碎瓦曬鹽。；瓦片曬鹽:井仔腳鹽田的瓦片較易吸收日曬熱能，據說曬出的鹽粒細小而潔白。
- 還缺：1 個

### budai 布袋
- 已有特點：小上海:布袋光復初期與廈門船隻往來頻繁，鎮上曾有十幾處酒家與戲院，人稱小上海。；鹽田變漁塭:布袋一帶的鹽田曾曬鹽兩百年，廢曬後不少改成漁塭，如今以養殖文蛤聞名。
- 還缺：1 個

### peitian 朴子配天宮
- 已有特點：樸仔樹鎮殿媽:配天宮的鎮殿媽以巨大樸仔樹雕成，神像下方仍與樹根相連。
- 還缺：2 個

### shuishang 水上北回歸線標
- 已有特點：三處標誌:台灣的北回歸線標誌共有三處，分別在嘉義水上、花蓮瑞穗與豐濱。；漂移的線:水上北回歸線標所指的那條線並非固定不動，會因地軸傾角變動與歲差而緩慢飄移。
- 還缺：1 個

### hinoki 檜意森活村
- 已有特點：宿舍分區:宿舍依身分分區，木材街以南住日籍幹部，以北住臺籍幹部，鐵道邊住火車司機。；原工法:整修時採用原材料與原工法，步道還鋪了枕木與檜木塊。
- 還缺：1 個

### xiluo 西螺大橋
- 已有特點：鐵道並行:西螺大橋通車時橋上還鋪了台糖鐵道，汽車與小火車並行過橋。；通行費:大橋曾設收費站，汽機車連火車都要繳通行費。
- 還缺：1 個
