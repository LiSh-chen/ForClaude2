# 給 Gemini 的補充需求：「星霧大陸」環島 App 的地區與景點資料

## 背景
這是一個把走路步數換算成「環島台灣一圈」的 App。玩家走過每個鄉鎮市區時，會看到該區的 **三個特色標籤**，每個標籤配一句「你知道嗎」。每個景點（收藏卡）也有兩句「你知道嗎」。內容要**正確、可查證**，我會再抽查。

## 規則（務必遵守）
1. **每一個事實都要附 2 個互相獨立的來源網址**（優先：公所、縣市政府、文化部／國家文化資產網、交通部觀光署、維基百科、可靠新聞；兩篇互相轉載或同一家媒體不算獨立）。給不出兩個來源的事實，**不要寫**，換別的，或明說「查無」。
2. **不要憑記憶寫**。網址要是你實際查到、打得開的頁面。
3. 若各來源數字或年份不一致（例如建廟年、高度、面積），**不要選一個寫**，改寫「約」，或換一個沒有爭議的事實，並在備註說明有哪幾種說法。
4. 不用「最」「第一」「唯一」「全台最大」這類字眼，除非兩個來源都明確這樣寫。不寫價格、營業時間、人口排名這種會變的資訊。不要廣告語氣。
5. 標籤 2–5 個字；三個標籤盡量不同類型（地景、歷史古蹟、產業或美食、文化活動），要是走路經過或在地能看見、聽說的東西。查不到好標籤時，地名由來、歷史沿革（有官方資料）也可以。
6. 「你知道嗎」：繁體中文，**20–45 字**，單一事實；句中不要有半形 `|` 和 `:`（冒號用全形「，」或「：」）。
7. 區名請用現行行政區名稱。

## 輸出格式（請整份用純文字、每區一行，不要加編號或多餘說明）
鄉鎮區：
縣市|區名|標籤:你知道嗎|標籤:你知道嗎|標籤:你知道嗎

另外附一份來源表，每個事實一行：
區名｜標籤｜事實重點｜來源網址1｜來源網址2｜備註（有爭議的說法寫在這裡）

景點：
id|名稱|你知道嗎1|你知道嗎2
