# 特色敘述：寫作準則與已改的區域（基隆、新北、宜蘭）

## 準則（依你的意見）
1. 先講「讓人想去、記得住」的那一點：畫面、稀有、獎項／稱號、特殊成因、反差，不是行程或活動清單。
2. 不寫日常行為（散步、騎車、拍照、看外觀）和交通停車；除非那件事本身很特別。
3. 每個「可以做的事」都要說清楚它有什麼吸引人，說不出吸引人的就刪。
4. 稱號或獎項要有至少兩個來源（單一來源只寫事實，不寫稱號）；開放時間、票價、名額不寫，每年會變。

**中正區　和平島**
- 原：和平島公園夏季可玩海水泳池和兒童戲水池，泳池由舊九孔養殖場改建；退潮時還能預約走進阿拉寶灣看豆腐岩。
- 新：和平島的阿拉寶灣，海蝕岩裂成一格格像豆腐的方塊，被列入「全球最美21個日出觀測點」，日出時金黃陽光灑在岩面上。※

**中正區　三府王爺巡江**
- 原：農曆六月十五三府王爺聖誕，和平島社靈廟的王船沿正濱漁港一帶巡江；另有海上遊江，可報名坐船，2024年登錄為基隆民俗無形文化資產。
- 新：農曆六月十五三府王爺聖誕，和平島社靈廟的王船在乩童相隨下沿正濱漁港一帶巡江；王爺海上遊江已登錄為基隆民俗無形文化資產。

**信義區　信二防空洞**
- 原：信二防空洞是二戰時期挖的地下坑道，約300公尺，分東西兩坑，可入內走一圈，再搭電梯直達中正公園，步行到基隆塔。
- 新：信二防空洞是日本二戰時期挖的地下坑道，約300公尺，分東西兩坑，洞裡還留著燈泡、電線和通風口，岩壁滲出的泉水滴落有聲。

**汐止區　水返腳**
- 原：汐止舊稱水返腳，基隆河漲潮時海水逆流到這裡就折返；老街上的濟德宮因《通靈少女》取景而爆紅，也可沿河散步。
- 新：汐止舊稱水返腳，清代文獻記載潮水漲到此處折返，日治時期1920年改名汐止。

**汐止區　茶葉集散**
- 原：水返腳街曾是茶葉集散地，山上的烏龍與包種茶由河船運往大稻埕和艋舺，街邊還能看到陳萬乞古厝等老建築的外觀。
- 新：水返腳街曾是茶葉集散地，烏龍與包種茶由河船運往大稻埕；老街上濟德宮因《通靈少女》取景而爆紅，廟裡軟身媽祖的四肢關節可轉動、能換新裝。

**瑞芳區　水湳洞**
- 原：水湳洞選煉廠遺址依山層層疊疊，俗稱十三層遺址，1933年落成；從水湳洞停車場往上拍很壯闊，常和陰陽海、黃金瀑布排成同一條路線。
- 新：水湳洞的十三層遺址依山而建，遠看像飄在空中的荒廢宮殿，有「台版天空之城」之稱，晚上還會亮起琥珀色燈光。

**瑞芳區　猴硐**
- 原：猴硐車站一下車就是貓村，有貓雜貨店和貓走廊咖啡店；旁邊的煤礦博物園區有礦工紀念館，可體驗搭礦車。貓咪數量近年減少。
- 新：猴硐車站一下車就是貓村，貓咪在老礦村的巷弄間閒晃（近年數量減少）；礦工當年運煤的橋還在，園區裡可搭礦車進去，試操作鑿岩機等工具。

**瑞芳區　黃金瀑布**
- 原：黃金瀑布的水來自礦坑坑水，鐵質氧化沉澱讓岩壁染成金黃偏橘色，一日遊常和陰陽海、水湳洞走成同一條路線。
- 新：黃金瀑布的水是礦坑流出的礦水，鐵質氧化把岩壁染成金黃偏橘；下方的陰陽海，海灣黃褐色的水與外海藍色海水形成鮮明對比。

**貢寮區　卯澳漁村**
- 原：卯澳漁村保留百年石頭厝，石牆有平行砌、人字砌、亂石砌三種，可掃QR code聽語音導覽；卯澳灣水清，也有人來浮潛。
- 新：卯澳漁村保留百年石頭厝，石牆有平行砌、人字砌、亂石砌三種；卯澳灣水清見底，被潛水界人士讚為台灣浮潛天堂。

**貢寮區　石花凍**
- 原：貢寮澳底有石花菜產業與海女文化，石花菜經七洗七曬熬成石花凍，夏天吃很清涼；也有農遊行程可以認識海女。
- 新：貢寮澳底的海女在礁岩間採石花菜，經七洗七曬熬成晶瑩的石花凍，是夏天的清涼甜點；海女人數正在減少。

**貢寮區　草嶺古道**
- 原：草嶺古道從貢寮走到頭城大里，約8.5公里、全程約4小時；沿途有雄鎮蠻煙碑和虎字碑，埡口可望見龜山島，秋天有芒花季。
- 新：草嶺古道經過雄鎮蠻煙碑，翻上埡口後視野豁然開朗，大里聚落、太平洋和龜山島盡收眼底，秋天滿山芒花，全程約8.5公里。

**頭城鎮　龜山島**
- 原：龜山島是火山島，從烏石港搭船，登島要先上網申請、冬季封島；也可以賞鯨、繞島，海底溫泉讓島邊海水呈牛奶色。
- 新：龜山島是座火山島，龜首海底噴出硫磺熱氣，讓島邊海水呈牛奶色，龜尾的鵝卵石灘還會隨潮汐擺動；登島有名額限制。

**頭城鎮　搶孤**
- 原：頭城搶孤在農曆七月舉行，參賽者要爬上塗滿牛油的高聳孤棚，搶下頂端的順風旗；2006年指定為宜蘭縣民俗類無形文化資產。
- 新：頭城搶孤在農曆七月舉行，選手要爬上塗滿牛油的高聳孤棚，搶下頂端的順風旗，被譽為台灣鬼月奧運；2006年指定為宜蘭縣民俗類無形文化資產。

**壯圍鄉　哈密瓜**
- 原：壯圍位於蘭陽溪下游，砂質土壤加上日夜溫差大，素有哈密瓜故鄉之稱；夏天鄉公所辦健走活動，走完可拿瓜果小禮。
- 新：壯圍哈密瓜是果肉爽脆的脆質瓜，靠蘭陽溪高灘地的砂質壤土和日夜溫差養出濃郁香氣，每年只在3到6月種一季，產季很短。

**壯圍鄉　壯圍沙丘**
- 原：壯圍沿海有蛇行般的黑色沖積沙丘，綿延近三十公里；沙丘旅遊服務園區有遊客中心與展館，可騎車逛到海邊。
- 新：壯圍沿海的黑色沖積沙丘像蛇一樣蜿蜒近三十公里；黃聲遠設計的沙丘園區仿沙丘造型，清水模外觀不規則，連入口都不明顯，獲2019台灣建築獎佳作。

**五結鄉　冬山河**
- 原：宜蘭國際童玩節自1996年起每年夏季在冬山河親水公園舉辦，有戲水設施與獨木舟；冬山河自行車道約10公里，平坦好騎。
- 新：宜蘭國際童玩節自1996年起每年夏季在冬山河親水公園舉辦，結合戲水設施、互動展館與國際表演團隊。

**南澳鄉　傳道冰**
- 原：南澳建華冰店的傳道冰有紅豆、綠豆、花生，再淋上生蛋黃；相傳早年傳教士路過靠它補充體力，也有不加蛋的版本。
- 新：南澳建華冰店的傳道冰在紅豆、綠豆、花生上淋生蛋黃，蛋黃遇冰凝固、口感滑順不腥；相傳是早年傳教士路過補充體力的點心，也有不加蛋的版本。
