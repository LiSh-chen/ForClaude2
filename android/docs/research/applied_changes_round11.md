# 第十一輪：依使用者決定併入的修改（原／新）

使用者決定：劉銘傳隧道維持仁愛區；石門古戰場拿掉；龍岡米干不搬區、加強食物介紹；天空步道改以步道為重點；和平島維持原內容並改為「曾被報導為…」；草埔合唱拿掉；其餘依撰寫者建議。

## ✏️ 和平島
- 原：和平島的阿拉寶灣海蝕岩像一格格豆腐，入選「全球最美21個日出觀測點」；園區的海水泳池由舊九孔養殖場改建，夏天能在海蝕岩岸邊游泳。※
- 新：和平島的阿拉寶灣海蝕岩像一格格豆腐，曾被報導為「全球最美21個日出觀測點」之一；園區的海水泳池由舊九孔養殖場改建，夏天能在海蝕岩岸邊游泳。

## 🗑 刪除：草埔合唱
- 原：草埔國小學童用排灣語合唱，讓幾近失傳的排灣童謠再度響起，美麗和聲使獅子鄉有「台灣維也納」的美稱；每個村口都立著金色獅子像。
- 原因：使用者指示直接拿掉

## 🗑 刪除：石門古戰場
- 原：1874年日軍從車城射寮登陸，沿四重溪上溯，在牡丹鄉石門峽谷與牡丹各社族人激戰；牡丹社事件促使清廷設立恆春縣。
- 原因：Google 地圖顯示在牡丹鄉，牡丹鄉不在路線上，無處可放；使用者確認拿掉

## ✏️ 龍岡米干
- 原：平鎮龍岡一帶的眷村雲南小吃有米干與過橋米線，湯的乾拌炒的都吃得到。
- 新：龍岡的米干以純米製成，口感軟嫩，外型和製法近似粄條；湯米干常用豬大骨熬湯，配蛋花、豬肝、豬肉片和水醃菜，也可選米線或黃麵，還有雲南的過橋米線。

## ✏️ 天空步道
- 原：紅毛港文化園區的天空步道，前身是台電火力發電廠的運煤輸送帶；紅毛港2007年完成遷村，兩萬多位居民搬到鳳山、大林蒲。
- 新：紅毛港文化園區的天空步道是園區的制高點，前身是台電大林發電廠的運煤輸送帶，保留下來改漆成白色，橫跨園區，可俯瞰被大港環繞的園區，冬天風大時別有風情。

## 🗑 刪除：南港瓶蓋工廠
- 原：南港瓶蓋工廠前身是日治時期1940年代初成立的國產軟木工業，曾是台灣最大的瓶蓋生產基地，2015年部分建物登錄為歷史建築。※
- 原因：拿掉單一來源的「最大」後沒有畫面；依建議刪除
