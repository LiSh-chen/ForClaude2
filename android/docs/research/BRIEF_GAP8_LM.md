# 任務：景點卡片「你知道嗎」補完（第 8 輪）

## 規則
1. 每句必須是**標題沒有講過的新資訊**（標題說了什麼，你就不要再講同一件事）；兩句也要講不同面向。
2. 不要和 `town_tags_overview.txt` 裡該景點所在鄉鎮區已有的標籤重複（那是地區卡的內容，例如「頭城搶孤」「蘇澳冷泉」「福安宮龍袍」已被地區卡佔用）。先用座標判斷景點在哪個鄉鎮區，再對照。
3. 要有記憶點：具體、有畫面或有點意外的細節（做法、尺寸感、怪習俗、為什麼長這樣、有趣的設計或典故）；不要建於哪一年、列為古蹟、開館日期、面積這類流水帳。**不寫店家、不寫會過時的**。
4. 證據：兩個互相獨立的網頁都支持，或一個權威官方來源；不可憑記憶寫；不要「最／唯一／第一／全台／全國／僅存」；20–40 字；句中不要半形 `|` 與 `:`；句子開頭要講景點本身。
5. **整個任務最多 40 次 WebSearch（standard）**，WebFetch 連不上。搜尋用「景點名 冷知識 趣聞 特色 典故 為什麼」等。補不到就留空，寧缺勿濫。
6. 不要修改 repo 其他檔案、不要 git commit。

## 輸出
`gap8_lm_out_N.txt`（N 是你處理的檔名編號）：每行 `id|名稱|句子1[|句子2]`（只列新增）；`gap8_lm_out_N_sources.md`：`id | 句子摘要 | A或B | 網址1 | 網址2`。回報補了幾句。
