# 任務：景點卡片資料（需查證）

對象：`input_landmarks_NN.txt`（每行 `id|名稱|緯度|經度|現有十字簡介`）。這些是環島路線上的 46 張收藏卡。每張卡要：
1. 查證**現有十字簡介**是否正確（回報對/錯/有爭議）。
2. 補兩句「你知道嗎」，供卡片背面使用。

## 規則（重要）
1. **每一個事實至少要有 2 個互相獨立的來源**（官方網站、政府、維基百科、可靠新聞、館方；抄同一篇的旅遊文不算獨立）。只有一個來源的不要用。
2. WebFetch 連不到維基百科，用 WebSearch（standard，必要時 extended）；**不可憑記憶寫**。查不到寫 `查無`。
3. 「你知道嗎」：繁體中文，20–45 字，單一事實，有數字／年份照來源；來源互相矛盾就寫「約」或不用（並在來源檔說明）。避免「最」「第一」「唯一」除非兩個來源都明說。不寫價格、營業時間。不要廣告語氣。兩句要講不同面向（歷史／地景／文化）。
4. 同時核對座標是否在該地點（用搜尋結果的座標或地址推斷；有明顯偏差就回報）。
5. 不要修改 repo 其他檔案、不要 git commit。

## 輸出（檔名 NN 同輸入）
- `landmarks_NN.txt`：每張卡一行 `id|名稱|你知道嗎1|你知道嗎2`（句中不要出現 `|`）。
- `landmarks_NN_sources.md`：表格 `id | 名稱 | 現有十字簡介是否正確 | 事實重點 | 來源1 URL | 來源2 URL | 備註`，另列座標核對結果與未能查證項目。

完成後回報：完成張數、現有簡介有誤者、座標有疑問者。
