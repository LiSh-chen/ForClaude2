# 任務：鄉鎮區特色標籤（需查證）

對象：`input_towns_NN.txt`（每行 `縣市|鄉鎮市區`）。環島 App「星霧大陸」每個鄉鎮區要有 **三個特色標籤**，每個標籤配一句「你知道嗎」。玩家每走完一圈環島在該區解鎖一個。

## 規則（重要）
1. **每一個事實至少要有 2 個互相獨立的來源**（例：公所／縣市政府／文化部／觀光署／維基百科／可靠新聞；兩個旅遊部落格抄同一篇不算獨立）。只有一個來源的事實不要用，換一個能查證的特色。
2. 本環境 WebFetch 連不到維基百科，用 WebSearch（standard，需要時 extended）＋可連得上的頁面（WebFetch 失敗就改用搜尋摘要）。**不可憑記憶寫**；查不到就寫 `查無` 並換別的標籤。
3. 三個標籤盡量不同類型（地景／歷史古蹟／產業或美食／文化活動），且是走路經過或在地能看見的東西。標籤 2–5 個字。
4. 「你知道嗎」句：繁體中文，**20–45 字**，單一事實、可驗證；有數字或年份就照來源寫，來源之間數字不一致就不要用或寫「約」。不用「最」「第一」「唯一」，除非來源明確這樣說（並兩個來源都這樣說）。不寫會過時的資訊（價格、營業時間、人口排名）。不要廣告語氣。
5. 該區沒有足夠可查證的特色時，標籤可以用地名由來、地理位置、歷史沿革（官方資料可查）。
6. 不要修改 repo 其他檔案。不要 git commit。

## 輸出（只寫這兩個檔，檔名 NN 同輸入）
- `towns_NN.txt`：每區一行 `縣市|區名|標籤:你知道嗎|標籤:你知道嗎|標籤:你知道嗎`（不含任何多餘空行；這是 App 直接讀的格式，句中不要出現 `|` 或 `:`，冒號用逗號）。
- `towns_NN_sources.md`：表格 `區 | 標籤 | 事實重點 | 來源1 URL | 來源2 URL | 備註`，每個事實列兩個來源 URL 與一句各來源說了什麼；查不到的列在最後「未能查證」。

完成後回報：完成區數、哪些區做不滿三個、哪些事實來源不一致。
