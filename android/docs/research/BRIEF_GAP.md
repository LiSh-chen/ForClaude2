# 任務：補齊鄉鎮區標籤（需查證）

`gap_in_N.txt` 每行 `縣市|區名|還缺標籤數|已有標籤`。環島 App 每個鄉鎮區要有三個特色標籤，每個配一句「你知道嗎」。請替每區補到三個（補不到就補多少算多少）。

## 規則
1. **每一個事實至少要有兩個互相獨立的網頁佐證**（官方／政府／維基百科／可靠新聞，不同機構或媒體；轉載同一篇不算）。做不到就換一個事實，仍不行就不寫。**不可憑記憶寫**。
2. 搜尋額度很少：**整個任務最多 36 次 WebSearch（standard）**。WebFetch 連不上，不要用。一次搜尋要盡量找出該區的多個可用特色（例如搜「區名 歷史 古蹟 特產」），從同一批結果裡找兩個獨立頁面佐證，不要每個標籤各搜一次。從沒有任何標籤的區優先做起，額度用完就停。
3. 句子：繁體中文，20–45 字，單一事實；**不要出現「最」「唯一」「第一」「全台」「全國」「僅存」**（即使來源有）；年份數字來源不一致時寫「約」或換事實；不寫價格、營業時間；不要廣告語氣；句中不要半形 `|` 與 `:`。
4. 標籤 2–5 字、與已有標籤不重複；三個盡量不同類型。
5. 不要修改 repo 其他檔案、不要 git commit。

## 輸出 `gap_out_N.txt`
每區一行：`縣市|區名|標籤:句子|標籤:句子`（只列新增的標籤，一到三個；一個都補不到就不列該區）。
另輸出 `gap_out_N_sources.md`：每個事實一列 `區 | 標籤 | 網址1 | 網址2`（必須是你在搜尋結果裡實際看到的網址）。
完成後回報補了幾區、幾個標籤。
