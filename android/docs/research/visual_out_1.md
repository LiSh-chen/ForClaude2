## anping 安平古堡
1. 外觀特徵
   - 園區入口處有大片紅磚牆與紅磚砌成的層層階梯（來源 A）。
   - 最顯眼的是「紅頂瞭望塔」：塔身為紅白色系，頂部是 1975 年整修加上的紅色尖頂（來源 A、B、C 皆提到「紅白色尖塔」「紅色尖頂」）。這座塔不是荷蘭時代原物。
   - 真正的古蹟是塔旁的古城牆殘蹟：荷、鄭時代遺留的南垣（糯米磚牆）與半圓井；英文來源說南側紅磚牆外有榕樹根盤覆（單一來源 D，英文部落格）。
   - 園區含紀念館、瞭望台、古壁史蹟公園三部分。
2. 常見取景角度：從園區內仰拍紅磚牆／階梯加上紅頂塔；登塔可眺安平港與老街（來源 E）。
3. 容易畫錯
   - 把塔畫成荷蘭式石造城堡或古建築；它是 20 世紀的塔，底部（1944）加上紅尖頂。
   - 「塔身是白色」：搜尋只確認「紅白色」，有一則英文摘要說牆面曾刷白，來源互相矛盾。建議塔身以白為主、尖頂紅，牆體畫紅磚。
   - 不要畫成完整城堡，城牆為殘蹟。
4. 避免：「安平古堡／熱蘭遮堡」招牌文字（2022 年有更名爭議）、票價、開放時間。
5. 來源

   - B 新聞（新頭殼）https://newtalk.tw/news/view/2022-10-13/830914
   - C 公視 https://news.pts.org.tw/article/603950
   - D https://harindabama.com/2024/10/31/anping-where-modern-taiwan-began/
   - E 遊記 https://bunnyann.tw/angubao/
   - 塔身純白與否：證據偏弱、未取得塔的整體照片描述。

## peitian 朴子配天宮
1. 外觀特徵
   - 鎮殿媽是用老樸仔樹（朴樹）雕成，神尊下方樹根仍連在地下，故稱「請不動的媽祖婆／不動天后」（來源 A、B）。
   - 神帽為紙製、金色，有龍鳳與垂珠，為減輕對木質神首的傷害（來源 C，公視）。
   - 正殿神龕內媽祖神像眾多；虎爺供奉在供桌「上面」而非桌下，且身穿龍袍（來源 B、D）。
   - 廟宇為縣（市）定古蹟，傳統閩南廟宇（建築細節如屋頂、剪黏：未找到）。
2. 取景角度：正殿神龕正面；廟埕正面外觀（細節未找到）。
3. 容易畫錯
   - 樹種：廟史傳說為樸仔樹；公視報導另稱廟內枯死的老樹是「樟科」類植物，兩者不一致，建議畫成粗壯的樹幹狀底座，不要畫成樟樹。
   - 別混入新港奉天宮鎮殿媽（泥塑、逾兩公尺、雙腳踩地）的描述。
   - 神像坐立姿態：未找到；不要自行指定，傳統鎮殿媽多為端坐，但此點無來源。
4. 避免：匾額文字、廟名、神明名牌。
5. 來源

   - B https://news.tvbs.com.tw/life/2428571
   - C https://news.pts.org.tw/article/430255
   - D https://smiletaiwan.cw.com.tw/article/1460
   - 外觀（建築、神像姿態）證據弱。

## shuishang 水上北回歸線標
1. 外觀特徵
   - 現場是歷代標誌並存：第五代為三角形標誌塔，三面刻「北回歸線標誌」，碑頂為三個環圈構成的座標儀（來源 A、B）。
   - 第六代「太陽館」（天文展覽館）造型據稱似太陽；遊記形容像飛碟或太空梭，有圓頂，夜間亮藍光，樓高五層（來源 C、D、E）。各描述不一致，是比喻說法。
   - 館外有九大行星裝置藝術、泰坦二號火箭展示（來源 C、E）；園區另有太陽廣場、歷代標誌展示。
   - 標誌位於一號省道（台一線）旁。
2. 取景角度：從台一線旁看三角碑塔，背景帶太陽館圓頂；或正面拍碑塔。
3. 容易畫錯
   - 不要畫成白色圓柱／方尖碑；那是花蓮瑞穗（白色日晷造型）或靜浦的標誌。
   - 水上的碑是三角塔加三環座標儀。
   - 不要畫成大型黑色或金色圓球，沒有證據。
4. 避免：碑上「北回歸線標誌」文字、園區招牌、火箭上標示。
5. 來源

   - B https://student.hlc.edu.tw/hualien/action/file/418/20160930144618888.pdf
   - C https://travel.yam.com/article/129955
   - D https://travel.yam.com/post/915
   - E https://newtalk.tw/news/view/2017-05-13/86456
   - 太陽館確切外型證據偏弱（僅比喻性描述，未取得顏色與材質）。

## budai 布袋（好美寮一帶）
1. 外觀特徵
   - 好美寮：沿堤防進入後是沙洲，以潟湖為主景，岸邊有高大防風林（木麻黃，約 6 千棵人工造林）（來源 A、B）。
   - 海岸有沙灘，沙灘與防風林之間有溝渠；潮間帶、紅樹林、河口交會（來源 A、C）。
   - 好美里（舊稱虎尾寮）腹地有廢鹽田改成的漁塭，養文蛤，魚塭常見水鳥（來源 B）。
   - 布袋港含漁港、商港、遊艇港；牡蠣養殖區約有 2000–3000 個蚵架（來源 D，單一來源）。
2. 取景角度：從防風林緣看向沙洲與潟湖；夕陽時段的海面（夕陽倒影多與布袋鹽田／漁市相關，非好美寮，單一來源）。
3. 容易畫錯
   - 把台南七股鹽山、北門潟湖、高跟鞋教堂的景象混入。
   - 沙洲是低平沙灘，不是岩岸或熱帶白沙椰林。
   - 搜尋未發現風車、高蹺。
4. 避免：告示牌、遊客人群、垃圾（沙灘近年爆紅且有告示牌）、建築招牌。
5. 來源

   - C https://wetland-tw.nps.gov.tw/upload/file/20190605100452919.pdf
   - D https://swcoast-nsa.travel/en/attraction/details/1584
   - 漁港實際外觀（船型、碼頭）未找到；整體偏弱。

## hinoki 檜意森活村
1. 外觀特徵
   - 木造日式平房宿舍群，檜木（阿里山）為主，傳統日式高台式（床下通風孔，來源 A、B）。
   - 屋頂為紅色水泥瓦，與一般日式黑瓦不同（林業署，來源 C）；多數描述此點僅此一源。
   - 依職級分不同大小與格局；設有澡堂、招待所，園區是成排宿舍的小街道（來源 A、D）。
   - 入口有以檜木製作的「Hinoki Village」裝置；園區綠蔭環繞、屋瓦保留昭和樣貌（來源 B、E）。
2. 取景角度：從園區街道看成排木造宿舍，綠樹相伴；單棟正面帶庭院。
3. 容易畫錯
   - 屋頂不要畫黑瓦（林業署說是紅色水泥瓦）；牆面顏色未找到。
   - 不要畫成京都寺院、神社鳥居或和風商店街。
   - 棟數（28/29）不影響畫法。
4. 避免：店家招牌、品牌名、營運方資訊（2026 年初營運方更換）、遊客和服。
