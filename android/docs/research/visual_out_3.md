## taoyuan 桃園神社
1. 外觀特徵
   - 日式神社建築群，主體為台灣檜木造；含鳥居、手水舍、參道、石燈籠、中門、拜殿、本殿、左右朵殿、社務所（yam 遊記、newslens、2017 修復報導）。
   - 神社屋頂典型特徵為千木、鰹木與破風（nippon.com 通論；桃園本殿具體樣式未查到，不確定是否為神明造）。
   - 屋頂 2017 年換過銅板瓦（修復報導），故屋面應為銅板瓦（偏綠灰/銅色，細節單一來源）。
   - 參道為碎石或石板鋪面，兩側有石燈籠；園內有約 300 棵櫻花樹（tsunagujapan）。
   - 狛犬原在鳥居前，戰後遺失，現存一對外形接近台灣石獅（單一來源）。
2. 取景角度：從鳥居沿參道直視拜殿；參道兩側石燈籠為前景。
3. 容易畫錯：不要畫成台灣傳統廟宇（燕尾脊、彩繪）；拜殿戰後曾作忠烈祠，仍是日式木造。狛犬別畫成日式狛犬，現存近石獅。鳥居顏色／材質未查到，勿隨意定紅色。
4. 避免：招牌文字、「忠烈祠」匾額、開放時間牌。
5. 來源：https://travel.yam.com/article/131191 ；https://www.thenewslens.com/article/8409 ；https://newtalk.tw/news/view/2017-03-18/83151 ；https://www.tsunagujapan.com/zh-hant/religionarchitecture/
   - 屋頂樣式、鳥居顏色：未找到。

## shihsanhang 十三行博物館
1. 外觀特徵
   - 三組建築群：灰色清水混凝土三層量體（象徵山）、鋼構建築（象徵海）、斜倒約 17 度的八角塔（businesstoday、ntust 獎項頁、cw）。
   - 鋼構部分屋頂為緩斜線條，像沙丘或鯨背，結構軸線放射狀指向海；材質含老化金屬板、砂岩。
   - 兩道高牆朝向觀音山方向；八角塔像煙囪，整體像一艘大船（甲板＋煙囪）。
   - 館外有灰色長階梯、北側陽光廣場；春季流蘇白花與灰色混凝土對比（newtalk 2019）。
2. 取景角度：從北側陽光廣場回望——鯨背屋頂為甲板、八角塔為煙囪；或階梯上仰拍八角塔配混凝土牆。
3. 容易畫錯：整體色調是灰色混凝土與暗金屬，不是白色或彩色；八角塔是傾斜的，不要畫正；不是傳統博物館古典柱廊。傾斜 17 度指八角塔或全館，各來源說法不一。
4. 避免：館名招牌文字、展覽海報。
5. 來源：https://www.businesstoday.com.tw/article/category/80732/post/200305150003/ ；https://www.dt.ntust.edu.tw/index.php/prize/view?id=725 ；https://www.cw.com.tw/article/5003236 ；https://newtalk.tw/news/view/2019-04-18/234875

## dihua 迪化街
1. 外觀特徵
   - 一段北端「十連棟」（348–366 號）：紅磚造 2 層巴洛克式（仿洋樓）街屋，立面紅磚與灰色混凝土混搭，有豐富裝飾（newslens／udn blog／yam）。
   - 街屋底層為騎樓（亭仔腳）；閩南式街屋多為 1 層加半樓，紅磚木料；仿洋樓式為四柱三窗、2 層（遊記）。
   - 年貨大街期間封街、人潮擠滿，兩側店家（南北貨、藥材）；設有裝置拍照點。
2. 取景角度：沿街縱深看兩側連棟立面（從北端十連棟或臺北橋方向起算）；抬頭拍立面山頭裝飾。
3. 容易畫錯：不是全街都是巴洛克，閩南式低矮磚屋與洋樓並存；非夜市霓虹風格。山頭／山牆形狀、拱廊：未找到具體描述。紅燈籠：搜尋未見證據，勿當成標誌。
4. 避免：店招牌文字、當年吉祥物（如 2026 的「白爛貓」充氣玩偶）、活動標語。
5. 來源：https://www.thenewslens.com/article/248175 ；https://n.yam.com/Article/20210803852791 ；https://newtalk.tw/news/view/2021-08-02/614098 ；https://www.dcard.tw/f/travel/p/260876875
   - 外觀細節證據偏弱（多為活動報導）。

## finish 回到台北（臺北車站大廳）
1. 外觀特徵
   - 大廳中央地面為黑白棋盤格地磚（2011 年售票亭西移後鋪設，靈感為愛麗絲夢遊仙境）（cna／nownews）。
   - 中央空曠、周邊座位少；大廳空間挑高開闊（「空曠涼爽」，挑高細節未查到具體高度與天花板樣式）。
   - 假日大批東南亞移工在黑白格上席地而坐，成群聊天；節慶時連兩旁柱子旁都站坐著人。
2. 取景角度：站在大廳邊緣平視，黑白格地板延伸、人群散坐其上。
3. 容易畫錯：地板是黑白方格而非單色；人是席地成群而坐，不是排隊；2020 曾禁止席地、貼過笑臉地貼（時效性）。
4. 避免：招牌、時刻表文字；黑白格將於 2026/12 起改造，屬會過時物件，但圖像仍應畫為黑白格。
5. 來源：https://cna.com.tw/news/ahel/202609120083.aspx ；https://news.pts.org.tw/article/479301 ；https://newtalk.tw/news/view/2020-05-25/411551 ；https://www.nownews.com/news/6801115
   - 天花板／柱子樣式：未找到。

## checheng 車城福安宮 土地公神像（加查）
1. 外觀特徵
   - 主神福德正神為黑面型，戴宰相帽（官帽）、身穿龍袍，全身掛滿金牌（tvbs、setn、moneyweekly）。
   - 為從大陸奉迎的老神像（約 300 年）。
2. 取景角度：未找到。
3. 容易畫錯：坐姿或站姿：未找到。龍椅、拐杖、元寶：福安宮無證據；拄拐杖拿元寶是竹山紫南宮等他廟的特徵，勿混入。常見的白鬚慈祥土地公形象不適用，此尊為黑臉。「全台最大」為媒體用語。
4. 避免：匾額與對聯文字、金牌上的字。
5. 來源：https://news.tvbs.com.tw/travel/2910484 ；https://www.setn.com/news/1672308 ；https://www.moneyweekly.com.tw/_Article?AID=8039
   - 服飾描述多篇但來源可能互相引用；姿勢未找到。
