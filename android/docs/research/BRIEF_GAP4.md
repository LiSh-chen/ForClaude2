# 任務（品質重做）：找出「讓人一看就記得」的在地特色

`gap4_in_N.txt` 每行 `縣市|區名|還缺標籤數|已保留的標籤|已淘汰的標籤`。使用者看完前幾輪的內容後說：**很多介紹流於形式，只是把歷史翻出來，不是讓人想知道、一看就記得的當地特色。** 請替每個區補上真正有記憶點的特色標籤。

## 使用者最新指示
**「偏流水帳的都不要，請補完。」** 流水帳＝只是年份、建築介紹、「位於…是…」、地名由來、登錄古蹟、機構設施的簡介。這一輪缺的標籤就是被這樣淘汰掉的；請補上真正有記憶點的，補不出來就不要寫，不要為了湊數寫流水帳。

## 什麼是好的標籤
- 標籤是一個**具體名詞**：當地的招牌食物、特產、能看到的獨特景物、獨特的活動／習俗／工藝、有趣的人事物。旅人說「啊，那個地方就是有 ___」的那個 ___。
- 句子（「你知道嗎」）要讓人**想講給別人聽**：一個具體、有畫面或有點意外的事實（做法、數字、怪習慣、為什麼長這樣、怎麼吃、怎麼玩），而不是登錄年份或「位於…是重要的…」。
- 類型盡量搭配：吃／看／玩（節慶、體驗）／冷知識，不要三個都是廟。

## 不要的（已經被淘汰的類型）
地名由來、行政沿革、升格設區、建於哪一年、被列為歷史建築或古蹟（除非那件事本身有趣）、「是重要的信仰中心」這類空話、滯洪池／河川邊界／統計面積等行政或工程資訊、已關閉或會過時的東西、單純介紹「某某博物館收藏很多」。

## 例子
- 差：「汐止在1999年升格為汐止市，2010年隨新北市升格改制。」
- 好：「崁仔頂漁市在凌晨一點到五點進貨，由糶手當場喊價拍賣。」（有場景，一看就記得）
- 好：「猴硐因為聚集許多貓咪而聞名。」「頭城搶孤的參賽者要攀爬塗滿牛油的孤柱。」

## 證據規則
1. A 級：兩個互相獨立的網頁都支持（官方、政府、維基、可靠新聞）；B 級：一個權威官方來源（縣市政府、區公所、觀光署、文化部、國家公園等）。都達不到就換一個，**不可憑記憶寫**。
2. **整個任務最多 40 次 WebSearch（standard）**，WebFetch 連不上。搜尋建議：`區名 特產 必吃 有名`、`區名 在地特色 景點 一年一度`、`區名 觀光 必看`，從觀光局／縣市觀光網／新聞特寫找出「這個地方最有名的是什麼」，再用同一批結果找第二個獨立頁面。缺 3 個的區優先。額度用完就停。
3. 句子：繁體中文，20–40 字，單一事實；**不要「最」「唯一」「第一」「全台」「全國」「僅存」**；不寫會過時的（屆數、價格、營業時間、排名、已停業）；年份來源不一致時改寫為不含年份；不要廣告語氣；句中不要半形 `|` 與 `:`。
4. 標籤 2–5 字，不與已保留或已淘汰的重複。
5. 不要修改 repo 其他檔案、不要 git commit。

## 輸出
- `gap4_out_N.txt`：每行 `縣市|區名|標籤:句子|標籤:句子`（只列新增的）。
- `gap4_out_N_sources.md`：`區 | 標籤 | A或B | 網址1 | 網址2（B可空）`，網址必須是搜尋結果裡實際看到的。
回報：補了幾區、幾個標籤；哪些區找不到有記憶點的特色。
