# 第十三輪：依使用者決定的修改（原／新）

## ✏️ 新竹城隍廟
- 原：新竹都城隍廟相傳比淡水廳署遷到竹塹還早落成，是先有廟、後有衙門。
- 新：新竹都城隍廟前是小吃重鎮，肉圓、炒米粉、魷魚羹麵、貢丸湯和香菇肉燕湯都聚在這；每年農曆七月的竹塹中元城隍祭，上千信眾背著紙枷夯枷解厄。

## ✏️ 南鯤鯓
- 原：南鯤鯓代天府主祀李池吳朱范五位王爺，分靈廟宇遍布海內外；凌霄寶殿內有信徒捐獻黃金打造的玉旨牌。
- 新：南鯤鯓代天府主祀李池吳朱范五位王爺，分靈廟宇遍布海內外；信徒捐獻的黃金曾打造成金牌匾。

## 🗑 刪除：泥火山
- 原：新園與萬丹交界的鯉魚山一帶有泥火山，地底氣體夾帶泥漿噴湧而出，是歷史上常見的噴發地點。
- 原因：「歷史上常見的噴發地點」空泛、無來源；使用者提供鰻魚之鄉另補

## 🗑 刪除：舞鶴茶
- 原：舞鶴台地位於瑞穗，以小綠葉蟬叮咬茶菁製成的蜜香紅茶聞名。
- 原因：拿掉冠軍後只剩蜜香紅茶，與膨風茶重複，沒有畫面
