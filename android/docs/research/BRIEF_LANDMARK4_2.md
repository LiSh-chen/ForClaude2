# 景點卡補特點 — 查證簡報

## 任務
（第二輪補缺。上一輪已查過的候選與捨棄原因寫在每張卡的「已捨棄」，請不要重複，改找新的角度。）
「來台灣走走」每張景點卡要有**三個特點**，每個特點 = 短標題（2–8 字）＋ 一句說明。下面每張卡列出「已有的特點」和「還缺幾個」。請為每張卡**補足缺的數量**，只回傳新增的特點。

## 規則（違反就不能用）
1. **查證**：每一句都要有**兩個互相獨立的來源**，或**一個官方來源**（政府、管理單位、博物館、官方網站、國家公園、文化部資料庫等）。維基百科＋另一個獨立來源可以；兩個網站互抄不算兩個。附上你實際看過的網址。查不到就回報「查無可靠來源」，**不要硬湊**。
2. **說明句**：繁體中文，14–70 個字（含標點），一句講完，不用「最、唯一、第一、全台、全國、僅存」等絕對說法（要用就改成「相傳／約／之一」並有來源）。
3. **有記憶點**：讀完會想講給朋友聽的小事（為什麼這樣叫、怎麼來的、有什麼特別做法、看得到什麼）。**避免**乾巴巴的年表、建築面積、官方宣傳語、營業資訊。
4. **不講店家**：不要出現任何商店、餐廳、品牌店名。可以講食物、技藝、地景、活動、建築、人物。
5. **不重複**：不得與該卡「已有的特點」、同一張卡其他新特點講同一件事；也盡量不與其他卡重複。
6. **標題**：2–8 字，名詞片語，不要加冒號。
7. 只寫現在仍然成立的事；有爭議的說法請寫成「相傳」並說明至少兩種說法或來源。
8. 不要碰：政治評論、宗教優劣、價格、地址、電話。

## 回傳格式（寫成檔案，每張卡一段）
```
### <id> <名稱>
- 標題｜說明句（14–70字）｜來源1網址｜來源2網址（官方來源可只列一個）
- …（缺幾個就寫幾個；查不到的寫「查無可靠來源」）
```
最後再列一行「已查但捨棄」的候選與原因（一兩行就好）。

## 本組負責的卡（補缺第 2 組）

### luye 鹿野高台
- 已有特點：飛行傘:鹿野高台夏季氣流旺盛，長年是飛行傘訓練場，熱氣球活動也是由此點子而來。；泰平山:鹿野高台上方的泰平山起飛場海拔約九百公尺，飛行傘一路滑翔到龍田降落場。
- 還缺：1 個
- 已捨棄（請勿重複）：紅烏龍（鄉鎮頁已有）

### taimali 太麻里
- 已有特點：迎曙光:太麻里在排灣語意為太陽升起的地方，四五月可見旭日從綠島與蘭嶼之間升起。；地名舊稱:清代文獻把太麻里寫成兆貓裡、朝貓籬、大貓狸、大麻里等，日治初期才定為現在的寫法。
- 還缺：1 個
- 已捨棄（請勿重複）：金針山、釋迦（鄉鎮頁已有）

### hengchun 恆春古城

- 還缺：1 個
- 已捨棄（請勿重複）：改名恆春（鄉鎮頁已有）；西門門額玄武岩（單一來源）

### maobitou 貓鼻頭

- 還缺：1 個
