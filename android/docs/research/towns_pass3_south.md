# 中南部改寫對照（高美、恆春、駁二、鹿港等）

**清水區　高美濕地**
- 原：高美濕地因台中港北防沙堤的突堤效應淤積而成，2011年公告為國家級重要濕地。
- 新：高美濕地退潮時薄薄一層水面倒映天空和一整排風力發電機，黃昏染成金黃橙紅；這裡記錄到約132種鳥類。

**恆春鎮　瑯嶠改恆春**
- 原：恆春舊稱瑯嶠，相傳清末欽差大臣沈葆楨認為此地四季如春，因而改名恆春。
- 新：恆春古城光緒元年起建，東南西北四座城門都還在，居民至今穿過西門進出；舊稱瑯嶠，相傳沈葆楨覺得此地四季如春而改名恆春。

**鹽埕區　駁二**
- 原：駁二原是高雄港第二號接駁碼頭的倉庫群，2000年代初整建後轉為藝術特區。
- 新：駁二原是高雄港的倉庫群，大義倉庫旁的大港橋每天下午有旋轉秀，大義公園有1137張椅子排成的「椅子樂譜」，蓬萊倉庫有小火車。

**三民區　三鳳宮**
- 原：三鳳宮主祀中壇元帥，相傳建於1672年，是三民區三塊厝的守護神，香火鼎盛。
- 新：三鳳宮二樓樓台環繞中庭、掛滿大紅燈籠，被比擬為《神隱少女》的萬燈場景；農曆九月九日太子爺生日有遊行，2011年曾聚集203尊三太子神偶跳舞。

**七股區　黑面琵鷺**
- 原：七股曾文溪口濕地旁設有黑面琵鷺生態展示館，冬季是賞鳥的熱門地點。
- 新：全球約四千多隻黑面琵鷺，台灣就占五成以上，七股曾文溪口是主要越冬地；先頭部隊中秋前後飛來，大批在11到12月抵達。

**東石鄉　外傘頂洲**
- 原：東石外海的外傘頂洲是沙洲，其內側水域平靜，是當地養蚵的天然屏障。
- 新：外傘頂洲是東石外海的沙洲，被稱為「移動的國土」，每年向西南漂移約60到70公尺，過去40年因泥沙減少侵蝕掉上千公頃，卻仍護著蚵田。

**鹿港鎮　鹿港老街**
- 原：鹿港老街沿舊鹿港溪發展，屋後臨溪方便船隻卸貨，後來港口淤積，才失去昔日繁榮。
- 新：鹿港老街保留清代前店後港的長條形街屋，九曲巷彎來彎去是為了擋風，半邊井是富人把半口井開在牆外，讓鄰居和路人取水。

**湖內區　寧靖王**
- 原：湖內是明寧靖王屯墾之地，王殉國後留有衣冠塚供後人憑弔。
- 新：相傳受過明寧靖王恩惠的農民，把他葬在湖內並造假墳掩人耳目，留有衣冠塚與華山殿；他的五位妃子在他殉國前先自盡，台南五妃廟祭祀。

**獅子鄉　草埔合唱**
- 原：草埔國小學童的美麗和聲，讓獅子鄉有台灣維也納的美稱
- 新：草埔國小學童用排灣語合唱，讓幾近失傳的排灣童謠再度響起，美麗和聲使獅子鄉有「台灣維也納」的美稱；每個村口都立著金色獅子像。

**士林區　芝山岩**
- 原：芝山岩惠濟宮由漳州移民所建，清代漳泉對立時山上設隘門防禦，現僅西隘門完整留存。
- 新：芝山岩出土芝山岩文化、圓山文化等多層史前遺跡，文化部通過升格國定遺址；山頂惠濟宮要爬226階，廟前石獅的石球能在口中轉動。

**北區　開元寺**
- 原：北區開元寺前身是鄭氏家族的北園別館，1690年改建為官寺。
- 新：開元寺前身是鄭經所建的北園別館，方志記載是為母親而建，1690年改為寺，園內有亭台與小曲橋，1985年指定為古蹟。

**北區　臺南公園**
- 原：臺南公園1917年開園，園內有咾咕石砌成的歐風公園管理所。
- 新：臺南公園1917年開園，日治時期還有養梅花鹿、猿猴的小動物園；庭園石特地從日本運來250塊，園中有百年歐風小屋。

**前鎮區　前鎮漁港**
- 原：前鎮漁港1967年建港，帶動遠洋漁業產業鏈與大量就業機會。
- 新：前鎮漁港1967年建港，是遠洋漁船回港卸魚的基地，卸下鮪魚、秋刀魚、魷魚等漁獲，新魚市場推動「卸魚不落地」。

**苑裡鎮　藺草編織**
- 原：苑裡的藺草文化館在2005年開館,當時鎮內的藺草田只剩下約一公頃。
- 新：苑裡婦女從小學藺草編織，日治時期帽子和草蓆銷往日本；2005年藺草文化館開館時，鎮上藺草田只剩約一公頃，館內由阿嬤示範編織。

**苑裡鎮　灣麗磚瓦**
- 原：苑裡的灣麗磚瓦文物館為紅磚主題觀光工廠，保留製磚設備與長達162公尺的隧道窯。
- 新：灣麗磚瓦文物館是紅磚主題的觀光工廠，保留舊製磚設備和長長的隧道窯，園區有紅磚風車與紅磚橋，也能動手做磚雕。

**溪湖鎮　羊肉爐**
- 原：溪湖以羊肉爐聞名全臺，多數店家提供中藥湯頭，並強調溫體宰殺。
- 新：溪湖的三寶是糖廠、巨峰葡萄和羊肉爐，糖廠附近羊肉爐店密集，湯頭有清爽的藥膳和多種口味可選。

**福興鄉　福寶濕地**
- 原：福寶濕地有超過一百種水鳥，園區內設有漂流木裝置作品漂流光座標。
- 新：福寶濕地常有上百隻水鳥同時站在池邊，不用望遠鏡也看得到；出海口立著以漂流木做的地景裝置「漂流光座標」。

**小港區　天空步道**
- 原：紅毛港文化園區的天空步道，是由廢棄的運煤輸送帶改造而成
- 新：紅毛港文化園區的天空步道，前身是台電火力發電廠的運煤輸送帶；紅毛港2007年完成遷村，兩萬多位居民搬到鳳山、大林蒲。

**鼓山區　壽山**
- 原：壽山因石灰岩地形發達，山上有多處天然洞穴與豐富的獼猴生態。
- 新：壽山是台灣獼猴的重要棲地，園區常見野生獼猴，遊客邊走邊吃容易被搶食，登山口有學生解說員講解猴群習性。
