# 花蓮、臺東改寫對照

**萬榮鄉　摩里沙卡**
- 原：林田山林場在日治時期稱為森坂，日語發音近似摩里沙卡，當地人也以此自稱。
- 新：林田山在日治時期叫森坂，居民至今自稱「摩里沙卡」人；1960年代住了約兩千人，有「小九份」之稱，園區保留日式老屋、蒸汽機關車與舊鐵道。

**鳳林鎮　校長之鄉**
- 原：鳳林有校長之鄉之稱，校長夢工廠原是日治時期的鳳林支廳長官舍，後來做過校長宿舍。
- 新：鳳林的客家農家相信教育能改變命運，學長把校長甄試經驗寫成筆記代代相傳，成了「校長之鄉」；校長夢工廠原是日治時期的支廳長官舍。

**新城鄉　哆羅滿**
- 原：新城老街舊稱哆羅滿，因立霧溪淘金熱而繁華，淘金退去後才沒落
- 新：新城老街舊稱哆羅滿，立霧溪的砂金招來淘金客，全盛時街上有歌廳、電影院和酒家；淘金退去、蘇花公路改道後才沒落。

**瑞穗鄉　秀姑巒溪**
- 原：秀姑巒溪瑞穗一帶是台灣知名的泛舟地點，河道多彎道與急流。
- 新：秀姑巒溪從瑞穗順流而下二十多公里，河床落差約65公尺、有二十多處險灘；出了長虹橋溪面變寬，白色石塊散布水面，有「秀姑漱玉」之稱。

**壽豐鄉　鯉魚潭**
- 原：鯉魚潭是堰塞湖，據傳太魯閣族人從山上遠眺，見湖形像跳躍的鯉魚而得名。
- 新：鯉魚潭是河川襲奪與淤積形成的堰塞湖，約百公頃，環潭一圈約4公里；螢火蟲繁殖季時，點點螢光照亮漆黑的潭邊。

**富里鄉　六十石山**
- 原：富里六十石山海拔約八百公尺，山坡有三百公頃金針田，山名由來一說是山上散布的大石頭
- 新：六十石山海拔約800公尺，8到9月山坡鋪滿三百公頃金針花，涼亭可環視花海，遠處是中央山脈與花東縱谷。

**玉里鎮　璞石閣**
- 原：璞石閣是玉里的舊名，1917年東線鐵路通車後改名玉里，一說因為秀姑巒溪裡有許多白色璞石。
- 新：玉里舊名璞石閣，因溪中多白色璞石而改名；小鎮名氣來自玉里麵，和假日得先抽號碼牌排隊的橋頭臭豆腐。

**臺東市　卑南遺址**
- 原：卑南遺址是東部新石器時代的代表遺址，距今約五千三百到兩千三百年，1960年代末因台東新站鐵路工程而被發現。
- 新：卑南遺址有兩千多具石板棺，是環太平洋與東南亞地區規模龐大的石板棺墓葬群，地表還立著一根月形石柱，出土過人獸形玉玦。

**太麻里鄉　千禧曙光**
- 原：千禧曙光紀念園區是2000年英國BBC轉播太麻里曙光的地點。
- 新：2000年元旦，英國BBC把太麻里選為全球千禧年迎曙光的直播現場，千禧曙光園區就是當年的轉播地點，如今是追光族的元旦熱點。

**池上鄉　伯朗大道**
- 原：伯朗大道兩側沒有電線桿，電線已地下化，能飽覽廣闊的稻田景觀。
- 新：伯朗大道因伯朗咖啡廣告走紅，電線已地下化，路旁沒有電線桿，秋收時兩側是一片金黃稻浪，空氣裡滿是稻香。

**卑南鄉　知本溫泉**
- 原：知本溫泉在卑南鄉，是弱鹼性碳酸氫鈉泉，水色清澈，有美人湯之稱，日治時期就已開發。
- 新：知本溫泉是水色清澈的弱鹼性碳酸氫鈉泉，有「美人湯」之稱，日治時期就已開發，原本是卑南族知本系統的聚落。
