# 任務（嚴格版）：為鄉鎮區找「看一眼就記得」的在地特色

`gap6_in_N.txt` 每行 `縣市|區名|還缺標籤數|已保留標籤|不可使用的標籤（已淘汰）`。使用者逐條檢討後給的回饋，請**嚴格遵守**：

## 補充（第二次補查，額度還在，請放手找）
- 這是補完階段：上一輪補不到的原因多半是「搜尋方向偏地名由來」。請**先搜這區的特產與招牌料理**（「區名 特產」「區名 在地美食 招牌 料理」「區名 名產 伴手禮」），再搜地景與習俗。每區力求至少一個**吃的（料理或特產本身）**。
- **地名由來只有在有畫面、有意外感時才寫**（例：汐止水返腳＝潮水漲到這裡折返；清水牛罵頭＝其實和牛罵人無關）；單純「舊稱某某，因某某而得名」不要。
- 臺北市士林區要補**士林夜市**（列三樣招牌小吃，寫菜名不寫店名），新北市淡水區要補**淡水老街**（同樣列三樣）。其他有夜市／老街／市場小吃聚集的區也照此做。
- 「不可使用的標籤」欄是這區所有曾經被提出而淘汰的標籤，不要再提。

## 使用者的硬性要求
1. **店家不要寫**：不寫店名、不寫「某某路的老店／某某巷口的攤子」，因為店家可能消失。食物可以寫，但要寫成**「這個地方的招牌料理／特產」本身**（它是什麼、怎麼做、為什麼特別），不要寫在哪一家買。
2. **標籤和內容要對題**：標籤是什麼，句子的主詞就是什麼，句子要一開頭就講這個標籤。（反例：標籤「汐止魷魚羹」，內容卻從汐止老街寫起。）
3. **要有記憶點**：句子要有一個具體、有畫面或有點意外的細節（做法、材料、尺寸感、怪習俗、為什麼長這樣、名稱的趣味由來），讓人看完能講給別人聽。**沒有特色的介紹一律不要**：像「位於…，是…的景點」「前身是垃圾掩埋場整治成公園」「附近有古道可順遊」「小吃街約二十攤，人氣攤賣完就沒了」「漁市在凌晨進貨由糶手喊價」這類（看完什麼也記不住）。
4. **夜市／老街／廟口這類小吃聚集地**：標籤用地點名，句子要**列出至少三樣最具代表性的小吃**（寫菜名，不寫店名），例如「基隆廟口以鼎邊趖、營養三明治、天婦羅為招牌」。要列的是該地最有代表性的三樣，而不是隨便三樣。（有此類地點的區：基隆仁愛區（廟口夜市）、新北淡水區（淡水老街）、臺北士林區（士林夜市）、臺北大同區（迪化街／大稻埕）、臺南中西區（國華街／神農街一帶）、新竹北區（城隍廟周邊）、高雄鹽埕區、嘉義東區，請依實際判斷。）
5. 好的例子：「汐止舊稱水返腳，清代文獻記載潮水漲到此處折返」（名稱由來但有畫面）；「猴硐因聚集許多貓咪而聞名」；「頭城搶孤的孤柱塗滿牛油，各隊疊羅漢往上爬」。
6. 三個標籤盡量不同類型：一個吃（料理／特產本身）、一個看（地景、奇特景物、活動）、一個故事或習俗。不要三個都是同一種。

## 證據規則
- A 級：兩個互相獨立的網頁都支持；B 級：一個權威官方來源。都達不到就換一個，**不可憑記憶寫**。**整個任務最多 40 次 WebSearch（standard）**，WebFetch 連不上。建議一次搜尋要同時找出這區的多個特色（例如「區名 特產 招牌料理 在地人推薦」「區名 小吃 夜市 必吃」「區名 習俗 節慶 特色」），再從同一批結果找第二個獨立頁面。額度用完就停。
- 句子：繁體中文，20–40 字；**不要「最」「唯一」「第一」「全台」「全國」「僅存」**；不寫年份屆數價格營業時間；不寫會過時的（活動「曾」、已停業、短期展覽）；不要廣告語氣；句中不要半形 `|` 與 `:`。
- 標籤 2–6 字，不與已保留或不可使用的重複。補不到有記憶點的就不要寫，寧缺勿濫。
- 不要修改 repo 其他檔案、不要 git commit。
