# 任務：逐條核對 Gemini 給的鄉鎮標籤

`verify_in_N.txt` 每行 `縣市|區名|標籤|你知道嗎句子`，是 Gemini 提供的候選。它附的來源只是網站首頁或猜的維基頁，**不可信**。請你核對每一句是否有網路上的證據支持。

規則：
1. 每句用 **1 次 WebSearch（standard）** 查（關鍵字：區名＋標籤＋句中最具體的事實）。**整個任務最多 35 次搜尋，用完就停，沒查到的標 `?`。** WebFetch 連不上，不要用。
2. 判定：
   - `OK`：搜尋結果裡有**至少兩個互相獨立的頁面**（不同機構／媒體；官方、維基、新聞皆可）明確支持句中**每一個**事實（含年份、數字、「現存」「僅存」等限定詞）。
   - `FIX`：事實大致對，但有部分不對／不確定（年份、數字、誇大詞）；請給出**只含有證據支持部分**的改寫句（20–45 字，句中不要半形 `|` 與 `:`）。
   - `BAD`：被反駁，或找不到可靠支持。
   - `?`：沒查（額度用完）。
3. 不可憑記憶判定；`OK`/`FIX` 必須附你在搜尋結果裡實際看到的兩個網址。
4. 不要修改 repo 其他檔案、不要 git commit。

輸出 `verify_out_N.txt`，每行：`縣市|區名|標籤|OK/FIX/BAD/?|最終句子（OK 則原句，FIX 則改寫，BAD 與 ? 留空）|網址1|網址2|備註`
完成後回報各判定的數量。
