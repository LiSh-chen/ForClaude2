# 試辦（依新 SOP）：苓雅、斗南、民雄、大埤、福興、湖口（原／新）

## ✏️ 民雄鬼屋
- 原：民雄鬼屋是榕樹藤蔓爬滿的劉氏古厝，靈異傳說有多種版本。
- 新：民雄鬼屋是1929年商人劉溶裕蓋的紅磚巴洛克洋樓，約1950年代初被棄置，榕樹氣根爬滿牆面；常見的鬼故事是婢女投井，當地也有人說那口井其實是馬匹飲水的井。

## ✏️ 酸菜
- 原：大埤鄉是台灣酸菜的重要產地，產量居全台之冠。※
- 新：大埤酸菜用葉短梗粗、纖維較細的包心芥菜醃成，產量居全台之冠。

## ✏️ 酸菜醃桶
- 原：大埤的傳統酸菜桶非常大，一層芥菜一層鹽疊進去，再壓上重石發酵。
- 新：酸菜是把曬過的芥菜一層層入桶灑鹽，傳統上還要用腳踩、石頭壓實，約一個月才發酵成酸菜。

## ✏️ 高蹺鴴
- 原：福寶濕地的高蹺鴴有粉紅色長腳，走起來像踩著高蹺。
- 新：福寶濕地的高蹺鴴羽毛黑白分明，細長的雙腿是深粉紅色，在淺水裡漫步像踩著高蹺。

## ✏️ 湖口老街
- 原：湖口老街的紅磚街屋有巴洛克式立面，日治時期鐵路改道北移後，老街逐漸沒落。
- 新：湖口老街全長約三百公尺，1914年起蓋成紅磚街屋，立面是巴洛克式，拱門與騎樓比其他老街寬大；鐵路改道後逐漸沒落。

## ✏️ 三元宮
- 原：三元宮在湖口老街街頭，主祀三官大帝，大正七年（1918年）建成，是新竹縣定古蹟。
- 新：湖口老街一端是奉祀堯舜禹三官大帝的三元宮，另一端是蓋在舊車站原址的天主堂；每年聖誕節有舞龍隊在老街遊行，正月則有媽祖繞境。

## ✏️ 斗南車站
- 原：斗南車站旁的舊鐵道倉庫改建成他里霧文化園區，有漫畫館、電影館和環境教育館。
- 新：斗南車站1945年改建完成，是日本人在台灣建造的最後一座火車站，帶著日治晚期的幾何線條與簡化裝飾風格。

## 🆕 🏭 他里霧文化園區
- 新：斗南車站旁的舊鐵道倉庫改建成他里霧文化園區，有漫畫館、電影館、環境教育館和繪本館。

## 🆕 🏙️ 高雄85大樓
- 新：高雄85大樓地上85樓，主體高約347.5公尺，加上天線約378公尺；頂部是金字塔造型，1994年動工、1997年完工，原本規劃是百貨、主題樂園和飯店。

## 🆕 🎨 衛武迷迷村
- 新：苓雅的衛武迷迷村從2016年起舉辦國際街頭藝術節，各國藝術家在整齊的四層、七層樓社區牆面畫出大型壁畫，主題有海底世界、媽祖臉譜和海洋生物。
