# 外部查核意見的逐項核實（第十輪）

原則：外部意見不直接採用，逐項用獨立來源核對後才改。

## 查證屬實，已修正
| 條目 | 結論與修正 |
|---|---|
| 嘉義城隍夜巡（西區→東區） | 中研院寺廟資料庫等多處記載嘉義城隍廟在東區吳鳳北路168號，已把「城隍夜巡」移到東區 |
| 雨來菇 | 它是藍綠菌（藍綠藻），已改寫，不再稱植物 |
| 阿塱壹 | 旭海觀音鼻自然保留區是屏東縣政府公告，範圍在牡丹鄉旭海至觀音鼻；古道南段劃入保留區，已改寫為「從台東南田走到屏東旭海，南段劃入保留區」 |
| 外傘頂洲 | 雲林縣政府表示行政區劃屬雲林口湖鄉，沙洲漂到東石外海，兩縣一直有管轄爭議；已把「行政上屬雲林口湖鄉，卻一路漂到東石外海」寫進句子 |
| 黑面琵鷺 | 2026年全球同步普查：全球7,746隻、台灣4,719隻（約61%）；已更新為「全球約七千七百多隻，台灣占六成以上」 |
| 芝山岩 | 稻穀是炭化稻穀，不是化石；已更正 |
| 秀姑巒溪 | 長虹橋在豐濱鄉；已寫成「終點在豐濱的長虹橋」 |
| 石門古戰場 | 登陸點在車城射寮，激戰地在牡丹鄉石門峽谷；已改寫為兩者分開寫 |
| 迎王祭造價 | 2014年約700萬、2018年760萬、2021年約1000萬；已改為「數百萬到上千萬元」，不寫單一數字 |
| 加工出口區 | 2021年3月28日更名前鎮科技產業園區；已補「今前鎮科技產業園區」 |
| 東便門 | 多數來源是1804年（嘉慶九年）鳳山新城六座城門之一，且只有它留存；已改為「約建於清嘉慶年間」，並更正為「兩百多年」 |
| 大肚溪口 | 找不到近年的普查數字可驗證外部意見的「300到700隻」，但長期數量確實下降；已加上「早年高峰時曾有」，避免誤解為現況 |
| 南港瓶蓋工廠 | 各來源對創建年份有1941／1943年之說，已改成「1940年代初」 |

## 查證後不採用或保留
| 條目 | 說明 |
|---|---|
| 壯圍沙丘「近三十公里」 | 找不到來源能證實壯圍海岸線長度，也找不到「30公里是整條蘭陽平原沙丘帶」的證據；兩種說法都無法驗證，所以把數字拿掉，只留「蜿蜒」 |
| 紅毛港遷村去向 | 外部意見說「大林蒲不是安置地」，但我查到多篇報導都寫紅毛港居民去了鳳山與大林蒲（2011年統計有2,772人搬到大林蒲），所以原句不改 |
| 瑞穗溫泉「在萬榮鄉」 | 來源互相矛盾：有旅遊資料說在瑞穗鄉，也有地址寫萬榮鄉紅葉村。無法確定，所以暫不改，請你判斷是否要保留這條 |
| 合歡與武乃／母乃石滬 | 來源兩種寫法都有，無法判定正式名稱；已改成只寫「合歡石滬」，不再提另一座的名字 |
