# 給 Gemini 的補充需求（二）：景點卡片

每張景點卡要有：**兩句「你知道嗎」**（不同面向：歷史／地景／文化），並核對**現有十字簡介**是否正確。規則與（一）相同：每個事實附兩個互相獨立的來源網址、不憑記憶、來源不一致就寫「約」或換事實、不用「最／第一／唯一」除非兩個來源都明說、20–45 字、句中不要半形 `|` 和 `:`。

輸出格式：`id|名稱|你知道嗎1|你知道嗎2`，另附來源表：`id｜事實重點｜來源網址1｜來源網址2｜備註`。
