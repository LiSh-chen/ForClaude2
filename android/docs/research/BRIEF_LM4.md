# 任務（品質重做）：景點卡的「你知道嗎」

`gap4_lm_in.txt` 每行 `id|名稱|還缺句數|已保留的句子|已淘汰的句子`。使用者說：**很多介紹流於形式，只是把歷史翻出來，不是讓人想知道、一看就記得的特色。** 景點卡背面的兩句要讓人想講給別人聽：具體、有畫面或有點意外（怎麼來的、怎麼玩、做法、尺寸感、怪習俗、為什麼長這樣），而不是建於哪一年、被登錄為古蹟、開館日期、面積。兩句要是不同面向。
證據、用字規則同 BRIEF_GAP3.md（A/B 級證據、不憑記憶、不要最／唯一／第一／全台／全國／僅存、不寫會過時的資訊、20–40 字、句中不要半形 `|` 與 `:`）。**整個任務最多 35 次 WebSearch**，WebFetch 連不上。可用「景點名 趣聞 特色 冷知識」等搜尋，並用同一批結果找第二個獨立頁面。額度用完就停。不要修改 repo 其他檔案、不要 git commit。
輸出 `gap4_lm_out.txt`：每行 `id|名稱|新句子1[|新句子2]`（只列新增的），與 `gap4_lm_out_sources.md`（句子、等級、網址）。回報補了幾句。
