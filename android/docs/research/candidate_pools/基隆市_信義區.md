## 6. 讀取限制
- 搜尋工具只回摘要；vocus、smiletaiwan、keelunghihi、taiwan.net.tw 等經 curl 皆被擋。
- zh.wikipedia API 頻繁 429，主普壇、基隆濟安宮未讀到。
- 官方來源未讀；搜尋摘要有些把中正公園內物件歸中正區（主普壇），行政區證據彼此不一致。
- 搜尋工具對部分查詢（濟安宮、役政公園、基隆監獄）回報無結果。

## 7. 風險與審查提示
1. **D9（最重要）**：條目 B 與 C 都在中正公園，行政區證據：維基與信義區公所連結、兩個旅遊來源的地址寫信義區壽山路；但一個旅遊站把園內主普壇標為中正區，且摘要稱中正公園「跨兩區」。已知的官方／Google 地圖地址未能取得。建議審查者以 Google 地圖與官方地址確認觀音像與防空洞位置；若確認在中正區，B 與 C 應移出，信義區改補靈泉禪寺（備位）。
2. 條目 A 摘要稱砲台在信義區與中正區交界，但維基與摘要地址（教忠街）均寫信義區，信心較高。
3. 現有條目 C 與四四南村這類無關；信義區（基隆）僅此一條現有條目。
4. 若 B、C 都被移出，剩下 A 與備位靈泉禪寺（總分 7，記憶點 1，符合 ≥7 且記憶點 ≥1）。
