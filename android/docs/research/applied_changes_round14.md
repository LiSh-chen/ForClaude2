# 第十四輪：審查者第十三輪 FAIL 的修正（原／新）

## ✏️ 新竹城隍廟
- 原：新竹都城隍廟前是小吃重鎮，肉圓、炒米粉、魷魚羹麵、貢丸湯和香菇肉燕湯都聚在這；每年農曆七月的竹塹中元城隍祭，上千信眾背著紙枷夯枷解厄。
- 新：新竹都城隍廟前是小吃重鎮，肉圓、炒米粉、魷魚羹麵和貢丸湯都聚在這；每年農曆七月的竹塹中元城隍祭，信眾背上紙糊的枷鎖，象徵消除業障。

## ✏️ 南鯤鯓
- 原：南鯤鯓代天府主祀李池吳朱范五位王爺，分靈廟宇遍布海內外；信徒捐獻的黃金曾打造成金牌匾。
- 新：相傳南鯤鯓代天府源自一艘漂到北門海岸的船，船上有李池吳朱范五尊王爺神像；分靈廟宇遍布海內外。

## ✏️ 水晶教堂
- 原：北門遊客中心由洗滌鹽工廠改建，旁邊有白色鋼骨鑲水晶玻璃的水晶教堂，假日晚上會點燈。
- 新：北門遊客中心由洗滌鹽工廠改建，旁邊有白色鋼骨鑲水晶玻璃的水晶教堂。
