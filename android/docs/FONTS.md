# Fonts

- **Ma Shan Zheng** (馬善政), SIL Open Font License 1.1, Copyright 2018 The MaShanZheng Project Authors (https://github.com/googlefonts/mashanzheng).
  `app/src/main/res/font/ma_shan_zheng_subset.ttf` is a subset (about 20 KB) holding only the characters the console writes; to show more characters, subset the
  original font again with them (fontTools `pyftsubset`) and replace the file.
